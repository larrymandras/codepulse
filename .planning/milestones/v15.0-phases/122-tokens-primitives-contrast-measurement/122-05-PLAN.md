### The conversion contract (identical across all five sweep slices)

Tokens now available from `src/index.css` (all five themes): `--surface-0/1/2/3`, `--hairline`,
`--hairline-strong`, `--astridr`, `--status-ok/warn/error/info`, `--status-error-fill`,
`--status-error-on-fill`, `--duration-fast/normal/slow`, `--ease-house`.

PREFER the existing semantic utilities -- they already alias the ramp and are what the 30 shadcn
primitives use: `bg-background` = `--surface-0` (page) | `bg-card` = `--surface-1` |
`bg-popover` = `--surface-2` | `border-border` = `--hairline` | `bg-muted` / `text-muted-foreground`
for de-emphasised fills and ink. Reach for a bracket reference only when no alias fits:
`bg-[var(--surface-3)]` for hover-on-raised, `border-[var(--hairline-strong)]` for an emphasised
divider.

**Palette classes** -- `(bg|text|border|from|to|via)-(slate|zinc|gray|neutral|stone)-NNN`:
page fill -> `bg-background`; card/panel -> `bg-card`; raised/popover/dropdown/tooltip -> `bg-popover`;
hover on raised -> `bg-[var(--surface-3)]`; chip/track/skeleton -> `bg-muted`; any border ->
`border-border` (emphasised -> `border-[var(--hairline-strong)]`); dim ink (`-400`/`-500`) ->
`text-muted-foreground`; primary ink (`-50`/`-100`/`-200`) -> `text-foreground`. Opacity suffixes
survive (`bg-zinc-800/60` -> `bg-card/60`).

**Hex literals** -- `(bg|border|text)-[#rrggbb]` in a className: same table. A genuinely data-driven
hex (chart series, graph node) is NOT a surface -- record it in the ledger as out of scope for this
bucket, naming what it is, rather than forcing it to a surface token to turn a grep green.

**Motion** -- `duration-NNN`: 75/100/150 -> `duration-fast`; 200/250 -> `duration-normal`;
300/350 -> `duration-slow`; >= 400 -> `duration-slow` AND record the old value in the ledger, because
that is a real speed-up and must be auditable. Add `ease-house` where a transition carried no
explicit easing or a non-house one.

**Violet** -- `(bg|text|border)-(violet|purple|fuchsia)-NNN`: adjudicate EACH site by what the element
REPRESENTS. Astridr's identity/voice/agent/memory -> `bg-[var(--astridr)]` / `text-(--astridr)` /
`border-(--astridr)/40`, using the bracket-paren convention already live in
`src/components/StatusBadge.tsx:22-27`. Everything else -> re-hue to `--primary`, a `--status-*`, or a
neutral. One ledger row per site with the verdict and its reason.

### Counting discipline
`grep -c` = matching LINES per file including `path:0` rows; `grep -o | wc -l` = OCCURRENCES;
`grep -l | wc -l` = FILES. Name the unit before quoting a number. For any literal containing `#` or a
backslash use the fixed-string flag typed exactly as it appears on disk -- never hand-escape.

### Files explicitly NOT in this slice
`MetricCard.tsx`, `HeroStatsBar.tsx`, `chat/VitalsRail.tsx`, `forge/ForgeStatusBadge.tsx` and
`skills/IntakeStatusBadge.tsx` are excluded from every sweep slice; their token work belongs to plans
122-10, 122-12 and 122-13.
