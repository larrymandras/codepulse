### What plan 122-01 already built

`e2e/theme-contrast.spec.ts` carries two env switches added in wave 0:
- `A11Y_CAPTURE_DIR` -- writes `${dir}/${theme}__${page}.json` per cell, BEFORE the assertion, so a
  failing cell still captures.
- `A11Y_MEASURE_ONLY=1` -- skips the failing assertion so the whole 20-cell matrix completes in one
  pass. A11Y-01 is a SIZING requirement; failing at cell 1 measures 1 of 20.
The `fee96b5d` gate guard is untouched and must stay that way -- Phase 123's A11Y-03 exists to prove
it still holds, and this plan gives that proof its first data point.

`a11y-before/` holds the 20 control JSON files, committed BEFORE any `src/index.css` edit.
`122-CONTRAST-BASELINE.md` has its BEFORE and Rule-breakdown sections filled and its AFTER, Delta and
Named-pair sections stubbed as `PENDING`.

### The run invocation (from `package.json`'s `test:e2e:noauth:help`, verbatim)

`VITE_CLERK_PUBLISHABLE_KEY= npm run dev:noauth` -- from GIT BASH, never PowerShell (PS 5.1 silently
deletes an env var assigned the empty string, leaving the Clerk gate live and making every cell skip).
`dev:noauth` = `vite --port 5181 --strictPort --host 127.0.0.1`; never drop `--host 127.0.0.1`.
`playwright.config.ts`'s `webServer` is hardcoded to 5173 and will report itself healthy while these
tests target 5181 -- start `dev:noauth` FIRST, in its own process.

### The matrix and what is outside it

4 themes (cyan, emerald, readable, aubergine) x 5 pages (`/`, `/live-run`, `/analytics`, `/forge`,
`/graphs`). `amber` is excluded by D-04 -- it is not in `ThemeSwitcher`, so it cannot be measured
against a rendered page. `src/pages/` holds ~42 top-level source pages plus 5 in subdirectories, so
5 of ~47 routes are measured. D-24 requires that limit stated in this artifact, in this phase's
verification, AND in Phase 123's scope, with the unmeasured routes NAMED.

### The known figure, and why it is not the baseline

The one figure this project had before A11Y-01 was 234 violations on `[cyan] Dashboard` -- ONE CELL
of the matrix. `REQUIREMENTS.md`'s A11Y-01 line says "Do not plan against 234". The whole point of
this requirement is that the total was unmeasured. Report the real total; if it happens to land near
234, say so explicitly rather than letting a coincidence look like a confirmation.

### The delta discipline

Compute the delta PER CELL, not only as a grand total. A total can improve while a single cell
worsens, and Phase 123 plans cell by cell. Report improvements and regressions separately; a
regression in any cell is a finding this phase must disclose, not average away.
