### The conversion contract (identical across all five sweep slices)

Tokens now available from `src/index.css` (all five themes): `--surface-0/1/2/3`, `--hairline`,
`--hairline-strong`, `--astridr`, `--status-ok/warn/error/info`, `--status-error-fill`,
`--status-error-on-fill`, `--duration-fast/normal/slow`, `--ease-house`.

PREFER the existing semantic utilities: `bg-background` = `--surface-0` (page) |
`bg-card` = `--surface-1` | `bg-popover` = `--surface-2` | `border-border` = `--hairline` |
`bg-muted` / `text-muted-foreground` for de-emphasised fills and ink. Bracket references only when no
alias fits: `bg-[var(--surface-3)]`, `border-[var(--hairline-strong)]`.

**Palette classes** -- `(bg|text|border|from|to|via)-(slate|zinc|gray|neutral|stone)-NNN`:
page shell -> `bg-background`; card/panel -> `bg-card`; raised/popover/dropdown/tooltip ->
`bg-popover`; hover on raised -> `bg-[var(--surface-3)]`; chip/track/skeleton -> `bg-muted`; border ->
`border-border` (emphasised -> `border-[var(--hairline-strong)]`); dim ink -> `text-muted-foreground`;
primary ink -> `text-foreground`. Opacity suffixes survive.

**Hex literals** -- `(bg|border|text)-[#rrggbb]` in a className: same table. A genuinely data-driven
hex (graph node colour, chart series, calendar category) is NOT a surface -- record it in the ledger
as out of scope for this bucket, naming what it is.

**Motion** -- `duration-NNN`: 75/100/150 -> `duration-fast`; 200/250 -> `duration-normal`;
300/350 -> `duration-slow`; >= 400 -> `duration-slow` AND record the old value. Add `ease-house` where
a transition carried no explicit easing or a non-house one.

**Violet** -- `(bg|text|border)-(violet|purple|fuchsia)-NNN`: adjudicate EACH site by what the element
REPRESENTS. Astridr's identity/voice/agent/memory -> `bg-[var(--astridr)]` / `text-(--astridr)` /
`border-(--astridr)/40` (the convention live in `src/components/StatusBadge.tsx:22-27`). Everything
else -> `--primary`, a `--status-*`, or a neutral. One ledger row per site.

### Counting discipline
`grep -c` = matching LINES per file including `path:0` rows; `grep -o | wc -l` = OCCURRENCES;
`grep -l | wc -l` = FILES. Name the unit before quoting a number. Fixed-string flag for any literal
containing `#` or a backslash, typed exactly as it appears on disk -- never hand-escape.
