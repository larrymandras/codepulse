    literally wrote it, that ratchet would go GREEN while every animation silently lost its timing.

    the built CSS, and a live call site resolving to a non-zero computed `transition-duration`.

    `transition:` / `transition-duration:` / `transition-timing-function:` declaration in the file.
    Where the value is one of the house timings (120ms/200ms/320ms or a near neighbour that was
    clearly meant to be one), replace it with the corresponding `var(--duration-*)`. Replace every
    easing function with `var(--ease-house)` unless the curve is deliberately different -- and if it
