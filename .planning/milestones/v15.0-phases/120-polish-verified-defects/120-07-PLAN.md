### The e2e harness — non-obvious invocation contract
`npm run test:e2e` defaults to `playwright.config.ts`'s `webServer` on **5173, which is the GATED
server**. The keyless server is `dev:noauth` on **5181**, and per `package.json`'s
`test:e2e:noauth:help` script:
  - start `dev:noauth` in its OWN terminal FIRST — the config's `webServer` is hardcoded to 5173 and will
    report itself healthy while your spec targets 5181;
  - issue both commands from **GIT BASH, never PowerShell** — PS 5.1 deletes an env var assigned an empty
    string, silently leaving the Clerk gate live:
      `VITE_CLERK_PUBLISHABLE_KEY= npm run dev:noauth`
      `PW_BASE_URL=http://localhost:5181 npm run test:e2e:noauth -- polish-geometry`
  - `dev:noauth` pins `--host 127.0.0.1` deliberately, overriding `vite.config.ts`'s `server.host: true`,
    because that wide bind would expose an AUTH-DISABLED server on the tailnet/LAN. Never drop that flag.
Also note: Vite may bind `::1` only, so a `127.0.0.1` probe can report a healthy server as down. Probe
`localhost` and `[::1]`, or check `Get-NetTCPConnection -LocalPort 5181`, before concluding the server
failed to start.

`e2e/command-center-breakpoints.spec.ts` (317 lines). Copy four of its disciplines verbatim in shape:
