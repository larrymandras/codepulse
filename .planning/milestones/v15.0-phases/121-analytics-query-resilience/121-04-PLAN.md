<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Convex query → React render phase | A query throw during render is the untrusted event this plan contains. Before the rewire it crossed into `Analytics()` itself and unmounted the route. |
| child component subtree → `SectionErrorBoundary` | The containment boundary. React routes a render-phase throw to the nearest ANCESTOR boundary, which is why the call must live below the wrap. |
