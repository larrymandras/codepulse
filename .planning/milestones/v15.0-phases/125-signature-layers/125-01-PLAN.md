## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-125-01-01 | Spoofing | `eventTypeToHue` on a producer-supplied string | mitigate | A hostile or malformed `event_type` cannot claim Ástríðr's identity: the `astridr` branch requires the literal `run.` prefix or exact `chat.response`, and every unmatched string falls to `machine`. Asserted by test case (d), which explicitly `not.toBe("astridr")` on three unrecognised strings including the bare word `astridr`. |
| T-125-01-02 | Denial of Service | `eventTypeToHue` | mitigate | Pure string comparison against fixed prefixes/sets — no regex backtracking risk, no allocation per call, no map growth. `HUE_TOKEN` is a frozen 3-key record; nothing accumulates per event. |
| T-125-01-03 | Tampering | entry-chunk ratchet | mitigate | The ratchet is the control that detects an unreviewed bundle-size regression (including an accidentally-bundled dependency). Its own false-green mode — no `dist/` — is closed by the `skipIf` + `console.warn` shape and proven by mutation (b). |
| T-125-01-04 | Information disclosure | `e2e/signal-tokens.spec.ts` | accept | The spec reads only CSS custom-property colour values and writes RGB triples to test output. No credentials, no PII, no network calls beyond the local keyless dev server. |
