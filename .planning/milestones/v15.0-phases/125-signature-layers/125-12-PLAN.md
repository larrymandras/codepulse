<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local astridr-repo working tree → running production stack | `up --build` builds from disk, including any uncommitted work |
| container recreate → running jobs and their logs | A recreate interrupts in-flight work and destroys the prior container's evidence |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-125-12-01 | Tampering | building from a dirty working tree | mitigate | Full `git status --porcelain` audit with every path classified as this phase's or someone else's, presented to a human before the build. Nothing is staged, stashed or reverted on their behalf. |
| T-125-12-02 | Denial of Service | recreate interrupting a scheduled job | mitigate | The cron calendar is checked and what will be interrupted is named concretely in the checkpoint context, with `defer` as a first-class option. |
| T-125-12-03 | Repudiation | destroying the evidence of an interrupted run | mitigate | `docker logs` for every affected container is captured to files with recorded paths and line counts BEFORE the rebuild, because a recreate destroys them. |
| T-125-12-04 | Spoofing | a deploy that did not actually deploy | mitigate | Three independent checks rather than trusting the build output: the mandatory profile set is re-derived from the compose file, an in-container import probe reads the resolved `__file__` for the code the interpreter actually loads, and the before/after horizon probe observes the behaviour end to end. This repo has already been bitten by a container holding two copies of the code. |
| T-125-12-05 | Elevation of privilege | the new `estop_state` broadcast | mitigate | Already assessed in plan 125-03: read-only telemetry on an auth-gated socket, no new write path, no new control over the kill switch. Nothing in this plan widens it. |
| T-125-12-06 | Repudiation | loosening the probe to obtain a pass | mitigate | Explicitly prohibited. A still-`unknown` result is reported and triaged by the attribute value itself, which discriminates `unknown` (socket up, state unconfirmed) from `offline` (socket down). |
| T-125-12-SC | Tampering | npm/pip/cargo installs | mitigate | This plan installs nothing on the host. The image build installs Ástríðr's own pinned dependencies from its existing lockfile; no dependency is added or changed by this phase. |
</threat_model>
