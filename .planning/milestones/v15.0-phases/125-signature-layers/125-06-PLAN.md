breathing baseline, gated so it never burns a core behind a hidden tab and never animates for

correct.

subscribe, count, or mount anything — plans 125-09 and 125-11 do that.

```typescript
import type { EventHue } from "@/lib/eventHue";

export type EcgFeedState = "unavailable" | "idle" | "live";
export interface EcgBlip {
  /** epoch ms of the event, already normalised by the caller */
  t: number;
  hue: EventHue;
}
export interface EcgPalette { astridr: string; machine: string; error: string; baseline: string; }

/** Pure draw step, exported for direct testing against a recording 2D context. */
export function drawEcgFrame(
  ctx: CanvasRenderingContext2D,
  opts: { width: number; height: number; dpr: number; now: number;
          blips: readonly EcgBlip[]; feedState: EcgFeedState; palette: EcgPalette;
          animate: boolean },
): void;

export function PulseEcgCanvas(props: {
  blips: readonly EcgBlip[];
  feedState: EcgFeedState;
  windowMs?: number;   // default 60_000
  height?: number;     // default 96
}): JSX.Element;
```

<planner_corrections>
**Do NOT port `AvatarAura.tsx`'s colour probe.** `AvatarAura.tsx:239-257` reads
`getComputedStyle(probe).color` and number-matches it with a regex to get RGB channels. That
technique is the documented defect class in this repo — Tailwind v4 emits `oklch()`/`oklab()`, and
a number-scrape reads the HUE ANGLE as a channel. RESEARCH R-4 settled this empirically with pixel
readback in this project's own Playwright Chromium (149.0.7827.55): `ctx.fillStyle =
"oklch(0.7 0.15 200)"` is accepted and renders a correct pixel. Pass the resolved custom-property
string straight to `fillStyle`/`strokeStyle`. UI-SPEC:199's offscreen 1×1 round-trip is
unnecessary and must not be built.

**Keep the OTHER idea from `AvatarAura.tsx`**: re-resolve the palette on theme change via a
`MutationObserver` on `document.documentElement`'s `data-theme`/`class` attributes. That part is
correct and reused.

| T-125-06-01 | Denial of Service | unbounded rAF loop / unbounded blip array | mitigate | The loop is gated on `document.hidden`, on reduced-motion and on `readable`, and is cancelled in cleanup — the specific CPU-drift shape this repo has hit before on long-lived sessions. `drawEcgFrame` drops blips older than `windowMs` every frame, so a burst cannot grow the draw set without bound. | T-125-06-SC | Tampering | npm/pip/cargo installs | mitigate | This plan installs nothing. The canvas is native; no charting or colour-conversion library may be added — a `recharts` grep returning 0 is an acceptance criterion. |
