<objective>
Get `listRecentRuntimeWindow` onto the live self-hosted Convex backend, under an explicit human
decision about what else the working tree is about to ship.

be deployed before plan 125-11 mounts the hero. Plan 125-09 calls it imperatively inside try/catch

older-tree deploy has already silently deleted three live indexes on another session's active phase
in this repo's history.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local working tree → live production backend | A whole-directory deploy publishes whatever is on disk, including other sessions' uncommitted work |
| CLI default target → deployment identity | An unqualified `convex deploy` can resolve to the retired cloud deployment rather than the self-hosted instance |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-125-07-01 | Tampering | working-tree deploy in a shared checkout | mitigate | A recorded three-bucket audit of every dirty path, a hard STOP on a dirty `convex/schema.ts`, and a blocking human decision before the push. Deploying an older or foreign tree is a ROLLBACK in a whole-directory deploy system, not a subset. |
| T-125-07-02 | Tampering | schema/index rollback | mitigate | `git diff HEAD -- convex/schema.ts` must be empty before the push, and the deploy output is read for the `Deleted table indexes:` line — the only announcement this system gives. Either condition is an immediate stop. |
| T-125-07-03 | Spoofing | wrong deployment target | mitigate | `--env-file C:\Users\mandr\convex-selfhost\selfhosted.envfile` is mandatory and appears in the acceptance criteria as a literal. `-y` may be added but never substituted. `npm run deploy` is prohibited by name. |
| T-125-07-04 | Denial of Service | mass-mutation commands | mitigate | No `import`, no `--replace-all`, no bulk delete or patch, no container restart. The self-hosted single-node instance's MVCC tombstone GC cannot absorb mass deletes while serving load — the 2026-07-21/22 incident. |
| T-125-07-05 | Elevation of privilege | new public function reachable without credentials | accept | `listRecentRuntimeWindow` is public and, per `CLAUDE.md`'s SEED-008 decision, so is essentially every other Convex function here — the tailnet is the auth boundary, enforced by the LAN firewall block. It is a read-only, clamped, payload-free query. Hardening this one function in isolation is the exact shape SEED-008 REJECTED and is deliberately not done. |
| T-125-07-06 | Information disclosure | `convex env list` style probes | mitigate | No environment-listing command is run. `convex env list` masks against cloud but dumps `NAME=VALUE` against self-hosted — it is not needed here and must not be used. |
| T-125-07-SC | Tampering | npm/pip/cargo installs | mitigate | This plan installs nothing and modifies no source file. |
</threat_model>
