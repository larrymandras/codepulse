| T-125-13-01 | Denial of Service | arming E-Stop on a live stack | mitigate | This is a real halt of all agent processing, not a simulation, and it is deliberate — the criterion cannot be verified any other way. Every arm step in the checkpoint is paired with an explicit disarm step, and `estop.py:60-63` records that state is in-memory so `docker restart astridr-agent` clears a halt unconditionally as the recovery path of last resort. Task 1 supplies the exact disarm command before any arm happens. |
| T-125-13-02 | Repudiation | verifying from the tab that armed it | mitigate | The observation is explicitly staged in two windows, neither of which issues the command.
