<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| working tree → live production backend | `convex deploy` ships the working tree, not HEAD, in a shared checkout. Deploying an earlier commit is a rollback, never a subset. |
| janitor deletes → single-node SQLite MVCC | Mass deletes generate tombstones that stay in every index until `DOCUMENT_RETENTION_DELAY` collects them. This has taken the dashboard down before. |
| `schema.ts` → live indexes | A removed or renamed index is announced only by one line in the deploy output. |
