<settled_decisions>
PATTERNS.md seam 8 flags one open decision and it is SETTLED here:

**No `useGovernorDecisions` hook is created. The component calls
`useQuery(api.governorDecisions.listRecent, {})` directly**, exactly as `DeliveryHistory.tsx` does.

Reason: `useControlVerbSwaps.ts`'s convention deliberately collapses loading and empty into one
honest-empty default, but `112-UI-SPEC.md`'s States section requires the two to be DISTINGUISHED -
`undefined` renders a skeleton, `[]` renders the empty-state copy. A coalescing hook would make
that distinction unrepresentable. There is also no scope axis to merge here: `governor_decision`
carries no profile field, so `useControlVerbSwaps`'s two-query merge has nothing to imitate. A
one-line pass-through hook would be indirection with no consumer.

**Copy strings are fixed by the approved UI-SPEC and must be byte-exact:**
- Section title (passed to `SectionHeader`): `Governor Decisions`
- Error boundary name: `Governor Decisions`
- Empty heading: `No governor decisions yet`
- Empty body: `Decision history appears here once the interrupt governor evaluates its first proactive event (reminder, watch pulse, heartbeat, or a similar automated nudge).`
- Status labels: `Spoke` for `spoke: true`, `Held` for `spoke: false` - never `Failed`, never `Error`
- Held-reason prose, reusing `InboxCard.tsx:170-174`'s wording verbatim: `held during quiet hours`
  for `quiet-hours`, `held during focus mode` for `focus`, and the bare `held` for any other or
  absent value. That function is module-private in `InboxCard.tsx` - re-implement the same
  two-branch mapping locally with byte-identical strings rather than exporting it.
- Truncation caption when the row count equals the cap: `Showing the last N decisions — earlier decisions may exist.`
  with N interpolated from `GOVERNOR_DECISION_CAP`. Below the cap, follow `SwapHistoryList.tsx`'s
  own convention and state the actual count instead.

**Table columns, in order:** Status (icon + label, the focal point), Emitter, Priority, Reason, When.
</settled_decisions>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Convex query result -> rendered audit table | The UI presents these rows as server-confirmed facts about what the governor decided |
| Client bundle -> Convex server runtime | A value import from a module that imports `internalMutation`/`query` drags the server runtime into the browser bundle |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-112-01 | Spoofing | Rows rendered as "server-confirmed" governor decisions | mitigate | Upstream control, inherited: the only write path is `internalMutation` (plan 03, T-112-01), so no browser client can forge a row this surface would display. This component performs reads only and calls no mutation |
| T-112-02 | Denial of Service | The read backing this surface | mitigate | `listRecent` is bounded by `.take(GOVERNOR_DECISION_CAP)` server-side (plan 03); the component imports the same constant for its truncation caption so the on-screen claim and the server cap cannot drift |
| T-112-03 | Tampering | Client bundle pulling the Convex server runtime | mitigate | The cap is imported from the dependency-free `convex/governorDecisionsFilters`; an acceptance criterion asserts the component does NOT import from `convex/governorDecisions` |
| T-112-17 | Repudiation | A surface that renders "no decisions" while actually still loading | mitigate | The `=== undefined` branch is required by the UI-SPEC and enforced by paired negative assertions in the loading and empty tests; a coalescing hook was explicitly rejected in `<settled_decisions>` for this reason |
| T-112-18 | Information Disclosure | Rendering raw emitter/session identifiers | accept | `governor_decision` rows carry an emitter name, a priority, a boolean and an optional reason enum - no PII, no session token, no credential. The surface is behind the same Clerk-gated UI and tailnet boundary as the rest of Settings |
| T-112-SC | Tampering | shadcn / npm installs | accept | No install runs: `Table`, `Badge` and `Separator` are already vendored in `src/components/ui/`, per the UI-SPEC's Registry Safety table |
</threat_model>
