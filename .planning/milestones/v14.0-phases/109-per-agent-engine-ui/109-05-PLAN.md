<objective>
Replace raw `===` model-id equality with one shared, prefix-tolerant comparator at every site where
it is used, and guard each site behaviorally so the rule cannot silently regress per-site.

Purpose: the id-format split is real and documented. `mode:"inherited"` rows carry
vendor-prefixed ids (`anthropic/claude-sonnet-5`) because the boot seed reads
`profile.model_default` from config, while `mode:"pinned"` rows carry bare ids
(`claude-opus-4-8`) from the catalogue resolver — both visible in the Phase 108 live evidence. The
live consequence: one model in two formats reads as "Mixed brains", the provider dot goes neutral
for every `inherited` row, and — the highest-impact site, not named in the original decision —
the "genuinely landed" success toast silently never fires for an `inherited`-mode profile.
`resolveModelDisplayName` already tolerates the prefix, so display was never broken; equality is.
Output: one comparator, seven corrected call sites, seven behavioral guards.
</objective>

**The comparator's home and its existing sibling** (`src/lib/brainsApi.ts:239-242`, verified live —

```
/** Strips a leading vendor namespace: "anthropic/claude-sonnet-5" -> "claude-sonnet-5". */
function stripVendorPrefix(modelId: string): string {
  const slash = modelId.lastIndexOf("/");
  return slash === -1 ? modelId : modelId.slice(slash + 1);
}
```

`resolveModelDisplayName` (`:249-273`) already proves the correct two-step match: exact `id ===
modelId` first, then `stripVendorPrefix(e.id) === bare`. `modelIdsMatch` is that same two-step
comparison collapsed into a boolean.

The root cause is already recorded in the file at `:220-236` (`modelPreferences.primary` is
vendor-prefixed while live `swap.catalogue` ids are not) — the new export's docstring should cite
that block rather than re-deriving the explanation.

**The established "pure exported predicate, directly unit-tested" convention** this comparator must
match — three in-repo examples: `isBrainSwap` (`convex/controlVerbSwapsFilters.ts:29-31`),
`needsCostConfirm` (`BrainPickerRow.tsx:77-85`), `quotaLevel` (`BrainPickerRow.tsx:87-97`). Each
has a docstring naming (a) what calls it and why it must be the single source of truth, and (b)
which prior duplicated-logic defect the export exists to prevent. `needsCostConfirm`'s docstring is
the closest analog in spirit — it exists precisely so a keyboard path and a mouse path cannot
silently diverge.
