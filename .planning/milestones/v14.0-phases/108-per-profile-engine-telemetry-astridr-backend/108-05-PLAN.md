## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-108-02 | Tampering | unvalidated `args["profile_id"]` reaching the verb | transfer | Validation lives at the single dispatch entry point (`_handle_swap_set`, plan 108-04) against `ChannelRouter.known_profile_ids()`, fail-closed, before `verb.execute` is ever called. This verb deliberately does NOT re-validate: a spoken utterance's `match()` never produces a `profile_id`, so `swap.set` is the only source, and duplicating the check here would create a second place for the two to disagree. The consequence of the transfer is stated so it is auditable: if a future caller learns to populate `args["profile_id"]` without going through `_handle_swap_set`, it bypasses validation — the mitigation is that `SwapSetCommand`'s docstring and this comment both name `_handle_swap_set` as the only entry point. |
| T-108-20 | Repudiation | a refused or unresolved swap leaving no record | mitigate | D-13: all four outcomes emit `control_verb_swap` with `scope`, and plan 108-03's ingest case stores every one. Asserted by 8 tests (4 outcomes x scoped/unscoped). |
| T-108-21 | Tampering | boot seed presented as a live reading | mitigate | The seed carries `mode:"inherited"` and a distinct `selectionPath:"boot-seed"`, so a seeded row is distinguishable from a resolved one in the stored data rather than indistinguishable from live telemetry. A profile with no configured default is skipped rather than seeded with a placeholder. |
| T-108-22 | Elevation of Privilege | scoped swap silently widening to global | mitigate | Every branch test asserts the NEGATIVE (the other override was not written) as well as the positive, and the branch is mutation-checked. A test asserting only the positive would pass with both overrides written — which is the failure that turns a per-profile swap into an unintended global one (103-CONTRACT.md §7's named worst case). |
| T-108-SC | Tampering | package installs | accept | No packages installed by this plan. |
</threat_model>
