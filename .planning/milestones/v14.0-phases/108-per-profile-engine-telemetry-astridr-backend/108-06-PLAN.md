## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Convex query result → React render | Row fields (`target`, `resolved`, `reason`, `channel`) originate from Ástríðr and are rendered in the browser |
| browser client → `api.controlVerbSwaps.listByScope` | A public query callable by any holder of the shipped `VITE_CONVEX_URL` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-108-16 | Information Disclosure / XSS | rendering `target` / `reason` / `resolved` strings | mitigate | Rendered as React text children only. This plan introduces no `dangerouslySetInnerHTML` and no `innerHTML` assignment, so React's default escaping applies. Asserted by the `git diff` review in the acceptance criteria (no new hex literals / no raw HTML APIs). |
| T-108-23 | Information Disclosure | `listByScope` is a public query | accept | It returns swap-history metadata — model ids, verb, path, channel name — for a single-operator deployment behind optional Clerk auth, and the sibling `activeEngine.latestByProfile` is already a public `query` on the same axis. No message content, credential or PII is stored in `controlVerbSwaps`. Making it internal-only would break D-15's modal, which is the requirement's "and surfaced" half. |
| T-108-12 | Denial of Service | unbounded history read from the client | mitigate | `listByScope` is `.take(SWAP_HISTORY_CAP)`-bounded server-side (plan 108-02); the component cannot request more, and the cap is stated on screen so a truncated list is never mistaken for a complete one. |
| T-108-24 | Tampering | a history that implies every swap worked | mitigate | `describeSwapOutcome` maps refusals and unresolved outcomes to distinct kinds with distinct status tokens, and test 1 asserts a refusal renders as a refusal. This is the render-side half of D-13's "successes-only was rejected". |
| T-108-SC | Tampering | package installs | accept | No packages installed by this plan — `lucide-react`, `convex/react` and the shadcn primitives are all already present. |
