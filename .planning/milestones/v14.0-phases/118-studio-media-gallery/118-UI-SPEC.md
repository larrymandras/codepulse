## Spacing Scale

Declared values (must be multiples of 4) — identical to the scale already in use on
`Galdr.tsx`/`Bifrost.tsx`, no new values introduced:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, badge internal padding |
| sm | 8px | Chip internal padding, compact stacks (`space-y-2`) |
| md | 16px | Card internal padding, masonry column gap (`gap-4`), grid card gap |
| lg | 24px | Section spacing inside the Sheet detail panel |
| xl | 32px | (unused this phase) |
| 2xl | 48px | Empty-state panel padding (`p-10`, matches Galdr/Bifröst empty states) |
| 3xl | 64px | Page-level (`p-6` outer + component spacing composes to this at the page edge) |

Exceptions: none. The 44px icon-only touch-target exception does not apply — the page's only
icon-only controls are the Star toggle (both the card-level overlay instance and the Sheet
footer instance — see Icon-only control labels below), each sitting inside a `Button
size="icon"` (shadcn default target), consistent with Galdr's `Button variant="ghost"
size="icon"` pattern. Every other action on this page (Copy Recipe, Copy Path, Move to Trash,
Restore) is a standard `Button` carrying a visible text label alongside its icon — not
icon-only — so no touch-target exception applies to them either.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 12px (`text-xs`) | 400 (regular) | 1.5 |
| Label | 14px (`text-sm`) | 600 (semibold — shadcn `CardTitle`'s `font-semibold` default) | 1.4 |
| Heading | 18px (`text-lg`) | 600 (semibold) | 1.2 |

Two weights declared, both authored by this phase: 400 regular (body/meta/recipe text) and 600
semibold (card titles, section headers, chip labels, empty-state headings).

**Inherited primitive chrome (excluded from the authored scale).** `PageHeader`'s title renders
at 24px/700 bold (`src/components/PageHeader.tsx:18`, `text-2xl font-bold`) — a pre-existing
shared component this phase does not modify or override. It is deliberately **excluded
from — not merged into —** the scale above: the weight set this phase authors is {400, 600},
not {400, 600, 700}.

Recipe body, file paths, and any raw sidecar values render in `font-mono` (JetBrains Mono) at
the Body size — same treatment Galdr gives prompt bodies (`Galdr.tsx:213`), for the same reason:
these are literal machine strings the operator will copy-paste.

## Color

All values are **CSS custom properties**, never hardcoded hex (CLAUDE.md Styling section) — the
runtime theme switcher means the resolved hex changes per active theme (`cyan`/`emerald`/
`readable`/`aubergine`).

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` | Page background, empty-state panel fill |
| Secondary (30%) | `var(--card)` / `var(--border)` | Card surfaces, Sheet panel, Collapsible section borders, default (inactive) chip fill |
| Accent (10%) | `var(--primary)` | Active filter chip (border + 15%-opacity fill + text + `--glow-xs`, exact Galdr `FilterChip` treatment), the "Copy Recipe" primary button, the active Tabs indicator (Gallery/Trash) |
| Destructive | `var(--destructive)` (button) / `var(--status-error)` (badge/text) | The **Trash** tab's badge/count only, and the "X days until permanent deletion" caption on a trashed card. **Not** the delete (move-to-trash) icon button itself — see Destructive Confirmation below |

Accent reserved for: the active filter chip, the active Tabs segment, and the "Copy Recipe"
primary CTA button. Nothing else on this page uses `--primary` — thumbnails, badges, and
secondary buttons stay on the neutral/secondary palette so the accent stays legible as "the
one thing you can act on right now."

**Star / favorite color is deliberately `var(--status-warn)`, not `--primary`.** This matches
`Galdr.tsx:203` exactly (`fill: "var(--status-warn)", color: "var(--status-warn)"`) and that
file's own inline warning not to substitute a hardcoded amber literal. Reusing the same token
keeps "starred" reading identically across Galdr and Studio.

**Primary visual anchor.** Studio has no page-level "create" CTA (media only enters via
generators/watcher — see Page Shape), so the anchor differs from Galdr's "New Prompt button +
selected-card border" pattern. In the default Gallery view, the eye's first accent-colored
landing point is the **active filter chip** (`All` by default) — the one `--primary`-filled
element outside the content itself — before the gaze moves into the thumbnail grid, where the
images' own color/contrast (not UI chrome) carry the visual weight. Once the detail Sheet is
open, the anchor shifts to the **"Copy Recipe" button** — the only accent-filled control in the
panel, and the one action this whole surface exists to make easy.

## Page Shape

`/studio`, one route, one page component (`src/pages/Studio.tsx`), following the exact page
skeleton `Galdr.tsx`/`Bifrost.tsx` establish:

```
<div className="p-6">
  <PageHeader title="Studio" icon={Images} actions={<Search input />} />
  <p className="sync-caption">  {/* new — see Sync Legibility below */}
  <Tabs Gallery|Trash>
    <TabsContent value="gallery">
      <FilterBar />              {/* chip row + two Selects, see Filter Contract */}
      <CollapsibleSection "Styles" />   {/* default collapsed */}
      <CollapsibleSection "Models" />   {/* default collapsed */}
      <MasonryGrid rows={visibleGalleryRows} onCardClick={openDetail} />
    </TabsContent>
    <TabsContent value="trash">
      <MasonryGrid rows={trashRows} trashVariant onRestore={...} />
    </TabsContent>
  </Tabs>
  <SectionErrorBoundary name="Media">...</SectionErrorBoundary>
  <MediaDetailSheet open onOpenChange row={selected} />
</div>
```

No page-level "Add" button (unlike Galdr's "New Prompt" / Bifröst's "Add link") — Studio is a
read/curate surface over agent-written media, matching the design doc's "the dashboard just
renders" agent-as-admin principle. The only page-level input is Search.

**Sync legibility** (scope requirement: the ≤5 min ingest latency must be visible, not implied
as instant). Directly under `PageHeader`, one muted caption line:

> `Auto-syncs every 5 min · run /studio-sync for an instant sync`

`text-muted-foreground text-xs font-mono`, no icon, no interactivity — informational only. This
is the one new copy element this phase adds beyond the Galdr/Bifröst precedent, because neither
of those surfaces has an asynchronous ingest step to disclose.

## Layout Contract — Masonry Grid

**True variable-height masonry via Tailwind CSS multi-column layout — no JS masonry library,
no fixed-aspect crop.** This is the literal reading of design doc §4.3 ("masonry grid,
2–6 columns") and the only no-dependency way to achieve it (CSS Grid alone cannot pack
variable-height items; a JS masonry package is forbidden by CONTEXT.md).

```css
/* container */
columns-2 sm:columns-3 lg:columns-4 xl:columns-5 2xl:columns-6 gap-4
/* each card */
break-inside-avoid mb-4
```

Known tradeoff, stated so the executor doesn't "fix" it later: CSS-columns masonry fills
top-to-bottom per column before wrapping to the next column, so visual reading order is
column-major, not the row-major raster order a CSS Grid would give. This is accepted — the
design doc asked for masonry specifically, and the grid is sorted (newest-first, see below)
independent of the visual packing order, so nothing is lost, only the raster-scan reading habit
from Galdr/Bifröst's uniform grids does not carry over here.

**Card height is content-driven, not fixed.** Each thumbnail renders with `w-full h-auto` (no
`object-fit` crop) so the card's natural aspect ratio drives its height in the column. Use the
row's `width`/`height` schema fields (when present) as an inline `aspect-ratio` placeholder
style on the image wrapper *before* the image loads, to prevent layout jump — the same reason
`Skeleton` components in Galdr/Bifröst reserve space during `isLoading`.

**Default sort:** newest first (`createdAt` desc) — no favorites-float-up like Galdr, because a
visual gallery's recency is the primary signal; starred items are reachable via the Starred
filter chip instead of a silent reorder.

## Filter Contract

Two tiers, mirroring the "Galdr chip row, but bounded" shape — chips for small closed sets,
Select dropdowns for open-ended sets that will grow without bound as more models/projects are
used (a chip row for `model` would grow unreadable the way Galdr's `category` chips do not,
because categories stay small by convention while `model` slugs will not):

**Chip row** (identical visual treatment to `FilterChip` in `Galdr.tsx:143-172` — same active/
inactive classes, same `role="group"` pattern):
- `All` (default)
- `Image` / `Video` / `Audio` (the `mediaType` field)
- `Starred` (favorite = star icon, `var(--status-warn)`)
- `Missing Provenance` — new, not in the design doc's literal filter list but directly serves
  D-07's intent ("gallery's provenance-absent rows will show which skills are worth
  retrofitting first" — Deferred Ideas) and D-11's retrofit signal. Filters to rows whose
  `prompt`/`model`/`provider` sidecar fields are absent.

**Select row** (two `Select` dropdowns, right-aligned next to the chip row or on its own line
below it on narrow viewports):
- **Kind** — Any / Gen / Ref / Style (the `kind` field — 3 fixed values, chosen as a Select
  rather than a fourth chip row to keep the header from growing to two full chip rows)
- **Model** — Any / {distinct `model` values present in the visible rows, alphabetical}
- **Project** — Any / {distinct `project` values present, alphabetical}

Search input (page header, matches title bar text field on Galdr/Bifröst) matches against
`filename`, `prompt`, `model`, and `project` — same `matchesSearch` shape as `Galdr.tsx:96-105`.

Trash tab does not show the filter bar or the Styles/Models panels — it is a flat, deletedAt-
sorted (most-recently-deleted-first) list with only Search.

## Collapsible Panels — Styles & Models (design doc §4.3, unchanged by CONTEXT)

Two `Collapsible` sections, default **collapsed**, placed between the filter bar and the
masonry grid:

- **Styles** — a small fixed-aspect card grid (not masonry — this is a curated table, not a
  content feed) of `mediaStyles` rows: `previewMediaId`-resolved thumbnail (or an `ImageOff`
  placeholder using the same broken-thumbnail treatment as the main grid), `name`, `slug`.
- **Models** — a list of `mediaModels` rows: `name`, `provider`, `type` (as a small `Badge`),
  an `enabled`/disabled dot, `docsUrl` as an external link (reuse Bifröst's `ExternalLink`
  icon-plus-mono-URL treatment), and the `recipeMd` card body rendered as **plain text inside a
  `<pre>` block, `font-mono`, never `dangerouslySetInnerHTML`** — identical reasoning to
  Galdr's prompt-body XSS note (`Galdr.tsx:211-212`): `recipeMd` is agent-authored free text,
  rendering it as HTML would be a stored-XSS surface for zero benefit.

Both panels read directly from `mediaStyles`/`mediaModels` queries; this phase adds no
create/edit UI for either table (D-12: cards are seeded only by the agent after an actual
proven run, never authored blind in the UI).

## Media Card Contract

```
<Card className="break-inside-avoid mb-4 overflow-hidden">
  <div className="relative" onClick={openDetail}>          {/* thumbnail well */}
    <img w-full h-auto />  |  <BrokenThumbFallback />  |  <AudioPlaceholder />
    <StarOverlayButton className="absolute top-2 right-2" onClick={stopPropagation→toggle} />
    {noProvenance && <Badge className="absolute bottom-2 left-2">No provenance recorded</Badge>}
  </div>
  <CardContent className="p-3 space-y-1">
    <p className="truncate text-sm font-semibold">{filename}</p>
    <div className="flex items-center gap-2 text-xs text-muted-foreground">
      <Badge variant="outline">{mediaType}</Badge>
      {model && <span className="font-mono">{model}</span>}
    </div>
  </CardContent>
</Card>
```

- **Click target:** the thumbnail well (and the filename) opens the `MediaDetailSheet`. The
  star overlay button calls `stopPropagation()` so starring never opens the panel — same
  separation Galdr enforces between `CardTitle`'s `onEdit` and the sibling Star button
  (`Galdr.tsx:187-207`).
- **Star overlay** uses a semi-opaque backdrop (`bg-background/70 backdrop-blur-sm rounded-full
  p-1`) so it reads against any thumbnail brightness — this is the one deliberate divergence
  from Galdr's plain inline Star (Galdr's cards have no imagery competing with it; Studio's do).
- **"No provenance recorded" badge is visible on the card itself**, not only inside the detail
  panel — this is what makes D-07's acceptance gate work: a complete-recipe item and a
  no-provenance item must be visually distinguishable **in the same grid view**, not just after
  opening each one.

**Icon-only control labels.** Only two controls on this page are icon-only (no visible text) —
everything else (Copy Recipe, Copy Path, Move to Trash, Restore, filter chips, Tabs triggers,
Collapsible triggers) carries a visible text label and needs no separate `aria-label`:

| Control | Location | `aria-label` |
|---------|----------|--------------|
| Star toggle | Card thumbnail overlay (top-right) | `Toggle favorite {filename}` — same pattern as `Galdr.tsx`'s `aria-label={\`Toggle favorite ${prompt.title}\`}` |
| Star toggle | Sheet footer (Media Detail Sheet) | `Toggle favorite {filename}` — identical label, second instance of the same control |

**Broken/missing thumbnail state (D-01 neutrality).** The row exposes one resolved field,
`thumbnailUrl` — a plain string the UI treats identically whether it resolved from Convex file
storage or the local-static-origin fallback (D-01's outcome is unproven at spec time and the UI
must not assume either). On `<img onError>`, or when `thumbnailUrl` is null/empty, render:

```
<div className="aspect-video flex flex-col items-center justify-center gap-1
                 border border-dashed border-border bg-muted/30 text-muted-foreground">
  <ImageOff className="h-6 w-6" />
  <span className="text-xs">Thumbnail unavailable</span>
</div>
```

Same dashed-border/muted treatment as the page-level empty state, just card-scoped — a broken
thumbnail is still a real, clickable, star-able row (the detail panel still shows whatever
sidecar metadata exists; only the pixel preview is missing).

**Audio placeholder** (no visual frame exists for audio): same box shape as the broken-thumbnail
state but with an `AudioLines` icon and the filename, not an error tone (`border-solid`, not
`border-dashed` — this is expected, not a failure).

## Media Detail Sheet Contract

A right-side `Sheet` (shadcn `sheet.tsx`), same component Galdr's `PromptEditorDrawer` uses
(`PromptEditorDrawer.tsx:188`) for its detail/edit surface — reusing the established "click a
card, get a wide right-hand drawer" idiom rather than a center `Dialog`. **This is not the
forbidden lightbox (D-02):** the Sheet shows the same ≤200KB thumbnail already in the grid, at
a larger `max-h-80 object-contain` size — it never fetches or displays the original file.

Contents, top to bottom:
1. Thumbnail (bounded, same broken-image fallback as the card)
2. Filename, `mediaType` + `kind` badges
3. Recipe block — `prompt`, `model`, `provider`, `style`, `project`, `params` — each a labeled
   row; **any absent field renders "No provenance recorded"** in `text-muted-foreground italic`,
   visually distinct from a populated value (`text-foreground font-mono`, not italic). This
   pairing is the D-07 control-pair requirement realized at the field level, not just the
   card-badge level.
4. Technical facts — dimensions/duration, size, created date, absolute path (`font-mono`, small,
   with the **Copy Path** button beside it)
5. Actions row (`SheetFooter`, matches `PromptEditorDrawer.tsx:328` layout). Every control here
   except the Star toggle carries a **visible text label** (standard `Button`, icon + text, not
   icon-only): **Copy Recipe** (primary `Button`, `variant="default"`) · **Copy Path**
   (`variant="outline"`, `Copy` icon + "Copy Path" text) · **Move to Trash** (`variant="ghost"`,
   muted icon + "Move to Trash" text — not `variant="destructive"`, matching the no-alarm
   treatment established above) — omitted entirely when already viewing a Trash row, in favor of
   **Restore** (`variant="outline"`, `RotateCcw` icon + "Restore" text) in that context. The
   **Star toggle** is the one icon-only control in this row (no text label, same `Star` glyph as
   the card overlay) — see Icon-only control labels above for its `aria-label`.

"Copy Recipe" copies a single formatted plain-text block (prompt/model/provider/style/params) to
the clipboard — sized to be pasteable straight into `/studio-generate`. When provenance is
absent, the button is disabled with a tooltip: "No recipe to copy — this file has no sidecar."

## Trash View Contract

Reached via the `Tabs` control at the top of the page (`Gallery` | `Trash`, active segment gets
`--primary`, exact `Tabs`/`TabsList`/`TabsTrigger` primitives from `src/components/ui/tabs.tsx`).
Chosen over a filter chip or a header toggle button because Trash is a **structurally different
list** (different empty state, different card actions, different sort) rather than a filter over
the same rows — a `Tabs` switch communicates that distinction better than a chip that would sit
oddly alongside `Missing Provenance`.

Trash cards reuse the `Card` shape from the main grid with two changes:
- Thumbnail rendered at `opacity-60` (no grayscale — grayscale would fight with broken-thumbnail
  detection, since a broken thumbnail is already colorless) to read as "not currently active"
  without implying the pixel data itself changed.
- A caption replaces the model/type row: **"Deletes automatically in N days"** (`var(--status-
  error)` when N ≤ 3, otherwise `text-muted-foreground` — no red until the deadline is actually
  close), computed from `deletedAt + 30d`.
- Card click still opens the detail Sheet (read-only recipe view); the Sheet's action row swaps
  Move-to-Trash for **Restore** as stated above.

No manual "delete forever" control exists in this phase (CONTEXT.md's `<specifics>`: "the doc's
gate stops at [move-to-trash, hide, restore]" — permanent deletion is the 30-day janitor's job
only).
