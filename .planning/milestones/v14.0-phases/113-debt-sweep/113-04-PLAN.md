<objective>
Move the ~57 existing plugin-sourced `skills` rows off the shared `claude-code` origin and onto
`claude-code:plugin`, using a one-shot, batch-capped, dry-run-by-default migration derived from each
row's stored `source` path.

Purpose: D-02 changes what the producer EMITS; it does nothing to the 188 `claude-code` rows already
in the table. D-04 explicitly rejects letting the next scan self-heal them — that heal runs through
the exact prune path being hardened, and a transient plugin read during it would delete 57 rows with
nothing replacing them. Every one of those rows is unambiguously classifiable today: research
confirmed all 188 carry a string `source`, of which 57 match a `.claude\plugins\` path.

Output: `reoriginPluginSkills` in `convex/migrations.ts`, unit coverage for its path predicate, and a
recorded before/after origin census read back from the live self-hosted backend.
</objective>
