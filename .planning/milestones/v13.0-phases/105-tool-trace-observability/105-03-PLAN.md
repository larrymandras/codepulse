<objective>
Stop discarding Ástríðr's tool telemetry at the CodePulse ingest boundary.

Purpose: two live-verified gaps. (1) `toolExecutions` contains ZERO Ástríðr agent tools — only
Claude Code hook rows and gateway pseudo-tools — because `case "tool_executed"` only upserts a
cumulative `callGraphEdges` counter, so OBS-01's "over time" is architecturally impossible today.
(2) `runtimeIngest.ts`'s switch has **no `case` for `tool_policy_event` and no `default`**, so all
four kinds Ástríðr emits are silently dropped and have never once been stored.

Output: a new `toolPolicyEvents` table with an `internalMutation`-gated writer, a second write in
the `tool_executed` case tagged `provider: "astridr"`, a `round` join key on both `llmMetrics` and
`toolExecutions`, a retention entry so the new table cannot grow unbounded on the self-hosted
instance, and pure-function parsers that are actually unit-testable.
