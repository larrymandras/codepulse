**F1 — the live Convex is SELF-HOSTED at `http://127.0.0.1:3210`, single node, SQLite.** Prove the

**F2 — the astridr containers run `feature/brain-swap`, and they can be running code that predates
the checkout.** 104-11 found exactly this: both containers were on pre-`9adb25b6` code and the fix
was a REBUILD, not a merge. Verify by grepping INSIDE the running container for a string only plan
105-02's commit contains — never by file timestamps (`docker inspect` build time looks identical for
a live-mounted and a stale container).

**F3 — only FOUR themes are reachable.** `src/index.css` defines six `[data-theme]` blocks but
`index.html`'s pre-paint script and `ThemeSwitcher` both hard-whitelist `cyan`, `emerald`,
`readable`, `aubergine`. `amber` and the light `:root` are unreachable (pre-existing since Phase 89;
`:root` is a load-bearing base layer, not a dead theme). A "six-theme sweep" is NOT executable —
sweep the four and record why.

**F4 — Clerk-gated writes need a signed-in browser.** Nothing in this phase ships a mutation, so
this plan should need no signed-in session. If any step turns out to hit an auth gate, that is a
finding (a read that should be public is not), not a step to work around.

**F5 — `tool_call_leaked_as_text` is the hardest kind to induce** — it fires only when the model
emits a tool call as literal text, which is by nature non-deterministic. Attempt a real induction
first (Task 2 gives a method). If it cannot be provoked, a direct `telemetry.send` from inside the
astridr container is an ACCEPTABLE fallback for proving the INGEST path, but it must be recorded as
exactly that: it proves the pipe and the view, NOT the detector. Do not record a synthetic event as
a detector verification.

**F6 — the D-04 aggregates only exist after `computeHourly` has run for a completed hour.** A tool
call made at 14:37 does not appear in a bucket until the ~15:00 run. Plan the induction early enough
in the session, or wait one cron cycle — do not conclude the buckets are broken from a chart that is
simply younger than one hour (104-11 hit exactly this with a 19:13Z turn and the 20:00Z rollup).
