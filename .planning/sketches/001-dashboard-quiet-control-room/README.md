# Sketch 001: Dashboard — Quiet Control Room

## Design Question

Does the approved verdict direction (calm matte surfaces, color spent only on state, Signal Horizon shell layer, Pulse ECG hero, quiet badges, regrouped sidebar) make the Dashboard feel premium while keeping CodePulse's soul — and which flavor of the ambient layer wins?

Source: the 3-model comparison at `html-out/ui-premium-redesign-comparison.html` (verdict tab).

## How to View

open .planning/sketches/001-dashboard-quiet-control-room/index.html

## Variants

- **A: Signal Horizon — quiet** — the pure verdict recommendation: hairline horizon under the header carrying event packets; plain-language truth line; graphite everywhere, cyan only where live.
- **B: Borealis blend — aurora + her voice** — same bones, plus the aurora gradient as the horizon's resting texture, an aurora wash behind the Pulse hero, and the truth sentence written in Ástríðr's serif voice ("dawn" disarm easing on E-Stop).

## What to Look For

- **The signature moment**: click **E-STOP** → proper confirm dialog (not a toast) → the horizon goes crimson shell-wide, agents gray out, the truth line rewrites. Disarm and compare the recovery (A: quick; B: eases back through amber like dawn).
- **Ambient reading**: stand back from the screen — can you read system state from the horizon + Pulse alone? Cycle calm/warn/critical/offline in the toolbar (bottom-right).
- **Pulse hero**: machine events (cyan), Ástríðr events (violet), errors (red spikes) landing on a breathing baseline — does it beat the old System Load gradient bar?
- **Quiet badges**: in Recent Executions, Done whispers, Running pulses, only Failed is filled. Does the failure pop the way it should?
- **Null-state honesty**: the "Memory hit rate" cell says "no signal yet" dimmed with a dotted baseline instead of "—".
- **Density toggle** (toolbar): the `--density` token at 0.85 — is compact worth keeping?
- **The serif voice** (B only): does Ástríðr speaking in italic serif feel like her, or like a different product?
