### The conversion contract (identical across all five sweep slices)

Tokens now available from `src/index.css` (all five themes): `--surface-0/1/2/3`, `--hairline`,
`--hairline-strong`, `--astridr`, `--status-ok/warn/error/info`, `--status-error-fill`,
`--status-error-on-fill`, `--duration-fast/normal/slow`, `--ease-house`.

The existing semantic utilities already alias the ramp, so PREFER them -- they are shorter, they are
what the 30 shadcn primitives already use, and they need no bracket syntax:
`bg-background` = `--surface-0` (page) | `bg-card` = `--surface-1` | `bg-popover` = `--surface-2` |
`border-border` = `--hairline` | `bg-muted` / `text-muted-foreground` for de-emphasised fills and ink.
Only reach for a bracket reference when no semantic alias fits: `bg-[var(--surface-3)]` for
hover-on-raised, `border-[var(--hairline-strong)]` for an emphasised divider.

**Palette classes** -- `(bg|text|border|from|to|via)-(slate|zinc|gray|neutral|stone)-NNN`:
- page-level container fill -> `bg-background`
- card / panel fill -> `bg-card`
- raised / popover / dropdown / tooltip fill -> `bg-popover`
- hover state on a raised surface -> `bg-[var(--surface-3)]`
- de-emphasised chip / track / skeleton fill -> `bg-muted`
- any border -> `border-border` (emphasised divider -> `border-[var(--hairline-strong)]`)
- dim body ink (the `-400`/`-500` weights) -> `text-muted-foreground`
- primary ink (the `-50`/`-100`/`-200` weights) -> `text-foreground`
Opacity suffixes survive the swap (`bg-zinc-800/60` -> `bg-card/60`).

**Hex literals** -- `(bg|border|text)-[#rrggbb]` in a className: map to the nearest token by the same
table. If a hex is genuinely data-driven (a chart series, a graph node colour) it is NOT a surface --
record it in the ledger as out-of-scope-for-this-bucket rather than forcing it to a surface token, and
say which it is.

**Motion** -- `duration-NNN`: 75/100/150 -> `duration-fast`; 200/250 -> `duration-normal`;
300/350 -> `duration-slow`; anything >= 400 -> `duration-slow` AND record the old value in the ledger,
because that one is a real speed-up and must be auditable rather than silent. Add `ease-house`
wherever a transition previously carried no explicit easing or carried a non-house one.

**Violet** -- `(bg|text|border)-(violet|purple|fuchsia)-NNN`: adjudicate EACH site.
- The surface represents Astridr herself (her identity, her voice, her agent, her memory) ->
  `bg-[var(--astridr)]` / `text-(--astridr)` / `border-(--astridr)/40`. Use the bracket-paren form the
  repo already uses for status tokens -- see `src/components/StatusBadge.tsx:22-27`
  (`text-(--status-ok)`, `border-(--status-ok)/40`); it needs no `@theme` registration.
- Anything else -> re-hue to `--primary`, to the correct `--status-*`, or to a neutral. Violet is
  Astridr's and only hers (TOKEN-02's three-hue-owner law).
Record the verdict and the reason for every site.

### Counting discipline
`grep -c` counts matching LINES per file, and emits a `path:0` row for every file scanned.
`grep -o | wc -l` counts OCCURRENCES. `grep -l | wc -l` counts FILES. Name the unit before quoting
any number. For any literal containing `#` or a backslash use the fixed-string flag (`grep -F`,
`git grep -F`, `rg -F`) typed exactly as it appears on disk -- never hand-escape.

### Files explicitly NOT in this slice
`MetricCard.tsx`, `HeroStatsBar.tsx`, `chat/VitalsRail.tsx`, `forge/ForgeStatusBadge.tsx` and
`skills/IntakeStatusBadge.tsx` are excluded from every sweep slice; their token work is owned by the
primitive plans (122-10, 122-12, 122-13) so no file is touched twice.
