### The vocabulary these conversions read

`src/lib/metricState.ts` defines the six states with their default copy, icon and tone --
`"no signal yet"` is the fixed empty phrasing and lives there, not at the call site.
`src/components/EmptyState.tsx` renders it at panel/page scale. D-20 permits a per-site copy override
wherever genuine context exists; the default is a fallback, not a ceiling.

D-19's boundary: the same backend condition must READ identically at tile scale and panel scale
without both scales RENDERING identically. In a dense table a full `EmptyState` panel per cell is the
wrong scale -- use a cell-scale affordance drawing on the same vocabulary. If a cell-scale renderer
does not exist in the shared module yet, add it there rather than inlining a string in a table.

### The population, with its unit named

Measured during planning across `src/**/*.tsx`, non-test:
`git grep -lE '(: *|\?\? *)"—"'` -> **28 FILES**, `git grep -hoE '(: *|\?\? *)"—"' | wc -l` -> **52
OCCURRENCES**. Fourteen of those files are this plan's; the rest belong to plans 122-14 and 122-15.
CONTEXT.md's D-15 quotes 27, which matches neither figure -- it measured a different pattern or a
different scope. Re-derive, name your regex verbatim, and reconcile explicitly. Do not adjust your
measurement to match the document.

Use a FIXED-STRING matcher for the em-dash character itself, typed exactly as it appears on disk.

### What is NOT a placeholder
An em dash is legitimate typography in a range, as a unit, in a label or in prose. Only an em dash
rendered WHERE A VALUE WOULD GO is the defect. Read each site.
