<objective>
Make "over time" real for tool usage, and wake someone up when Ástríðr's tool-access policy fails
open — both riding the one cron this project is allowed to attach to.

Purpose: `convex/retention.ts` prunes `toolExecutions` at 14 days, and plan 105-03 just added
Ástríðr's entire tool volume to that table on the self-hosted instance whose tombstone GC caused the
2026-07-21/22 outage. Retention is NOT raised. Instead the hourly rollup writes tool buckets that
outlive the raw rows. Separately, Ástríðr *deliberately fails open* on a malformed tool-access
policy — `load_config()` degrades `tool_clusters` to a blank-slate permissive policy so a config
typo can never fail boot — and that silent widening of tool access is invisible beyond a local log
line today.

Output: four new hourly `aggregates` metric types keyed `{tool, provider}`, and a fail-open-only
alert evaluator appended to `computeHourly`'s tail. Zero new crons. Zero new delivery code.
</objective>
