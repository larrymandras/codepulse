    Create `WorkspaceMapCanvas.tsx`. Props: the `getWorkspaceMap` payload, and a callback the page
    uses to open the side panel with the selected `WorkspaceMapNode | null`.

    **State:** `expandedSet: Set<string>` of `nodeKey`s, in component state. Initial value is empty —
    the 391-node first paint comes from `layoutNodes`' `visibleDepth` floor of 2 (plan 114-07), not
    from pre-seeding the set.

    **Two separate `useMemo` boundaries — this is a correctness-shaped detail, not a micro-optimization.**
    `buildTree` and `computeRollups` depend only on the payload and must memoize on the primitive
    `payload.activeVersion`, **not** on `payload.dirs`: whether Convex's client returns a
    referentially-stable array across renders is not verified (114-RESEARCH.md logs this as assumption
    A1), and `activeVersion` is a stable number that changes only on the nightly re-push, so it is
    correct either way. `layoutNodes` memoizes separately on `[tree, rollups, expandedSet]`, because
    that one legitimately changes on every click. Collapsing all three into one memo conflates a
    once-a-night input with a per-click one.

    **The `ForceGraphCanvas` mount:**
    - `data={{ nodes, links }}` from `layoutNodes`.
    - `cooldownTicks={0}` — the prop plan 114-01 added. Physics off (D-08).
    - **No `clusterForce`** (omit it or pass `false`). It is `CodeVaultGraph`'s d3 community-clustering
      mechanism and would actively fight a fixed `fx`/`fy` layout.
    - **No custom `paintNode`.** UI-SPEC resolved this deliberately: the shared default paint already
      gates labels on `globalScale > 1.4 || hovered`, handles hover-to-white and `focusSet` dimming,
      and draws the halo. A tiered label scheme was considered and rejected as ~60 lines of custom
      paint for marginal benefit.
    - `colorFn` — a `useCallback([colors])` department lookup:
      `Personal → colors.deptPersonal`, `Consulting → colors.deptConsulting`,
      `Work → colors.deptWork`, `Unclassified → colors.mutedForeground`. The **center hub also uses
      `colors.mutedForeground`** — it has no department and is already unmistakable by being the
      largest node at the exact center.
    - `communityColorFn` — `useCallback([colors])` returning `colors.statusInfo` when
      `node.access === "astridr-reachable"` and `null` otherwise. `local-only` gets no halo, which is
      what keeps 3,389 of 4,912 directories from becoming one flat color. This degrades gracefully
      when `accessDerivationOk` is false: every dir already carries `local-only` in that state, so the
      halo simply never renders — no special-casing needed here (the coverage strip is where that
      state is *stated*, plan 114-06).
    - `labelFn` — the privacy-aware label (below).
    - `defaultNodeColor={colors.primary}` and `defaultLinkColor={colors.primaryAlpha18}`, matching
      `CodeVaultGraph.tsx:663-664`'s convention even though `colorFn` means the node fallback never
      engages.
    - `onEngineStop={() => fgRef.current?.zoomToFit(400, 60)}`.
    - Reuse the fullscreen toggle pattern from `CodeVaultGraph.tsx:582-605` verbatim in shape
      (`h-[600px]` default, `h-[calc(100vh-48px)]` fullscreen, ESC to exit).

    **`onNodeClick` (D-03).** Always report the clicked node to the page so the panel opens or
    updates. Additionally: if the node has children and is not in `expandedSet`, add its key — one
    level, never a subtree. If it is already in `expandedSet`, remove its key **and every descendant
    key**, so a re-collapse does not leave orphaned deep nodes visible. Leaf nodes affect only the
    panel. When the currently-selected node is collapsed out of the visible set, clear the selection
    so the panel does not go on describing an invisible node (114-RESEARCH.md § Open Question 2; the
    panel's fallback from plan 114-08 handles the resulting `null`).

    **Labels and masking (D-15).** Gate on `enabled && maskPaths` from `usePrivacy()`. Masked, a root
    node's label is `"{department} root {index}"` with the index assigned by descending rolled-up
    file count within the department (compute it once, memoized, and pass the same index to the panel
    so the two surfaces agree); a directory node's label is the `redact()` placeholder `"••••••"`.
    Department hubs, the center hub, all positions, sizes and colors are **never** masked. Do not use
    `maskPath`/`maskFilePath` — verified at `src/lib/privacy.ts:9-17` to return single-segment input
    unchanged, i.e. a silent no-op for exactly the case that needs masking.

    **Three-state branch on the payload:** `undefined` → the skeleton radial placeholder (concentric
    dashed rings inside the canvas card, per UI-SPEC's States table — not a bare spinner, not the
    text-pulse `CodeVaultGraph` uses); `null` → the true-empty copy ("No workspace snapshot yet." /
    "The nightly scan (04:15) hasn't produced one. Check `CodePulse-WorkspaceScan` in Task Scheduler,
    or wait for the next run.") with no action button; payload → the canvas.

    No hardcoded hex anywhere. Lucide icons only.
