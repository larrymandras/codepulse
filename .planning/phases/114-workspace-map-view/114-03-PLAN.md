## ⚠ SYNTHETIC ROOT AND DIRECTORY NAMES ONLY — READ THIS BEFORE WRITING A SINGLE LINE

`larrymandras/codepulse` is a **PUBLIC** repo. Several of the real root directory names in Larry's
live workspace tree read like client engagements, and 7 of ~10 of them appear in **zero** tracked
files at HEAD — committing one would be a new, permanent, one-way disclosure, because git history
survives deletion. This is Phase 115's **D-17**, carried forward verbatim by 114's D-16.

Therefore: every root id, directory path, and label in this fixture — and in every test that consumes
it, and in every screenshot taken anywhere in this phase — is **invented**. Use names of the shape
`root-a`, `root-b`, `acme-client`, `demo-vault`. Do **not** open the live snapshot to "get realistic
names." Aggregate counts are fine and already published in 114-CONTEXT.md § Specific Ideas; names
are not.

**Any inline code in this plan is a DRAFT, not a spec** — correcting it beats transcribing it.
</context>
