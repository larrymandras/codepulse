<objective>
Build the Ástríðr lens's honest empty state as a **presentational, prop-driven** component.

Purpose: D-10 ships the lens switcher with Ástríðr's world as a stated empty state rather than a
blank canvas or a fixture-backed fake ARMS renderer. D-11 requires that state to be driven by a live
probe, not a hardcoded sentence — a hardcoded assertion about *another repo's* state is exactly the
line that goes stale silently and is never struck. Taking the probe result as a prop (rather than
calling `useArmsProbe` internally) keeps this component testable without a Convex mock and keeps the
data dependency visible at the page level.
Output: one component, one test file.
</objective>
