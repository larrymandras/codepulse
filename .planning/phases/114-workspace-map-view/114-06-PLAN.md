  <action>
    Create `WorkspaceCoverageStrip.tsx`. Props: the `getWorkspaceMap` payload (or `undefined` while
    loading). Render a `Card` containing a row of `Badge` chips.

    **Four healthy chips, always present, in this fixed order:**
    1. Scan time — "Scanned {relative time}" derived from `generatedAt`.
    2. Roots covered — "{coveredRoots.length}/{rootCount} roots covered".
    3. Withheld — "{totalWithheldFiles} files withheld".
    4. Unclassified — "{unclassifiedRootIds.length} roots unclassified".

    **Degraded treatment**, per UI-SPEC's copy table, using `--status-warn` styling plus a Lucide
    `AlertTriangle`:
    - `now - generatedAt > 36 * 3600` (epoch **seconds**, see below) → chip 1's text gains "— overdue"
      and takes warn styling.
    - `scannedRootsComplete === false` → chip 2's text gains "— scan incomplete" and takes warn styling.
    - `accessDerivationOk === false` → an **additional** chip appends: "Access data unreliable —
      compose parse failed, every directory shown as local-only". The copy says so explicitly rather
      than silently rendering wrong halos, because in that state every directory falls back to
      `local-only` and the halo channel is not trustworthy.
    - `localConfigStatus === "absent"` → additional chip "No local classification config —
      departments may be stale".
    - `localConfigStatus === "version-mismatch"` → additional chip "Classification config changed
      since last scan — departments may be stale".

    **Degraded chips append at the end; the healthy four never reorder and never disappear.** That
    stability is the exact property D-14 was chosen for.

    **Chip 4 (unclassified) never escalates, at any count.** 23 of 53 roots being Unclassified is
    expected and correct per Phase 115's D-15/D-16 — every ambiguous root was deliberately declared
    Unclassified rather than guessed into a department. It must not read as an alarm. Do not add a
    threshold.

    **Staleness math — read this twice.** `generatedAt` is epoch **SECONDS**
    (`convex/schema.ts:2400`, and `src/test/projectGraphFixture.ts:145-147` records the same
    convention). Compare against `Date.now() / 1000`, or multiply `generatedAt` by 1000 before
    comparing with `Date.now()` — but do exactly one of those, never neither. A missing conversion
    yields 1970 dates and a threshold check that passes vacuously; that is a failure class this repo
    has already recorded. The threshold is **exactly 36 hours** (one 24h scan cycle plus a ~12h grace
    window), binary, with no separate "approaching stale" tier — the relative-time text renders
    unconditionally either way, so the reader always has the raw number.

    Loading state (`undefined` payload): a row of four pill-shaped `Skeleton`s — never a blank div,
    never a bare spinner.

    No hardcoded hex. Lucide icons only. Extract the staleness predicate into a small exported pure
    function (e.g. `isScanStale(generatedAtSeconds, nowMs)`) so the boundary test can hit it directly
    with an injected `now` rather than mocking the system clock inside a render.
  </action>
