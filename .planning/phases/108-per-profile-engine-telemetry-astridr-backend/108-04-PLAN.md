<objective>
Give `swap.set` an optional profile scope, and give `ModelRouter` a per-profile override that
outranks the global one — while leaving the unscoped path byte-identical.

**Repos: `astridr-repo` (tasks 1-2) and `codepulse` (task 3).** Each task states its repo.

Purpose: ENGINE-02. Today `SwapSetCommand` carries only `target`/`value`/`restore`, and
`_resolve_model` has no per-profile rung at all — an operator cannot swap one agent's engine without
swapping every agent's.

Output: the override store and its precedence rung, the scoped command with fail-closed validation,
and the in-place correction of the contract those changes falsify.
</objective>

| T-108-01 | Elevation of Privilege | `swap.set` scoped to another profile | accept | The new field does not create a new authorization boundary. `swap.set` is ALREADY a process-wide command: today any holder of the service key can globally reroute every profile's engine via an unscoped call. Adding a scope strictly REDUCES the blast radius a given call can have; it grants no capability the caller lacked. The existing gate is `CommandAuth.check` (`command_auth.py:30-50`) plus the `/ws/telemetry` bearer handshake (`ws_telemetry.py:118-154`, constant-time `hmac.compare_digest`), and a per-profile authorization model would require a per-profile identity that Ástríðr does not have — inventing one here would be security theatre over a single-operator deployment. Recorded as accepted, with the reason, rather than asserted safe. `astridr/security/command_auth.py` stays untouched (asserted by an acceptance criterion). |
| T-108-02 | Tampering / Spoofing | unknown or unvalidatable `profile_id` | mitigate | Fail-closed validation in `_handle_swap_set` BEFORE dispatch: unknown id → `ValueError` error ack; validation source unavailable → reject rather than proceed; voice target + `profile_id` → reject. 103-CONTRACT.md §7 names the silent-global-apply as the single most dangerous failure mode here. Tests 3/4/6 assert the verb mock has ZERO calls, so "rejected" means "did not execute", not "raised afterwards". |
