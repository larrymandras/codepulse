| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-108-26 | Denial of Service | operating on the live single-node Convex instance | mitigate | Read-only queries plus one already-deployed schema migration. | T-108-02 | Tampering | scoped request silently applying globally | mitigate | Step 7 is a dedicated negative control: an unknown `profile_id` must produce an error ack AND leave state unchanged, proven by a row read rather than by the ack alone. 103-CONTRACT.md §7 names this as the single most dangerous failure mode of the whole design. |
