<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Convex query result → rendered dollar figures and model names | Model and provider strings originate from ingested telemetry and are rendered into the DOM. |
| one throwing query → the whole Analytics page | A throwing `useQuery` unmounts the React tree and blanks every page using it — the documented failure mode in this codebase. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-104-38 | Denial of Service | a throwing `costBreakdown` or `unpricedModels` query blanking Analytics | mitigate | Each new component is mounted inside its own `<SectionErrorBoundary name="...">` per the codebase convention, so one failing widget cannot take the page down. |
| T-104-39 | Repudiation | a total that silently absorbs unpriced traffic | mitigate | Unpriced rows render an `Unpriced` badge instead of a dollar cell, the excluded token count is stated in a caption, and a unit test asserts `$0.00` does not appear in an unpriced row. This is D-03 made visible rather than only enforced in the backend. |
| T-104-40 | Repudiation | billed and covered merged into one headline | mitigate | Two separately labelled footer figures and no summing expression; a unit test asserts no rendered element equals the sum of the two (D-05). |
| T-104-41 | Repudiation | a stale unpriced count | mitigate | The nudge renders directly from the live `useQuery` result with no local caching and no `localStorage`, asserted by a spy and by a re-render test. UI-SPEC states the count must never be stale. |
| T-104-42 | Information Disclosure | attacker-influenced model/provider strings rendered into the DOM | accept | React escapes text content by default and no `dangerouslySetInnerHTML` is used; these same strings are already rendered by the existing `CostBreakdown` and `CostTrendChart` surfaces. |
</threat_model>
