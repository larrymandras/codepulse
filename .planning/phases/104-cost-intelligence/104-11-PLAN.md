| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-104-47 | Denial of Service | `npx convex deploy` deleting an index on the live instance | mitigate | The deploy output must contain `No indexes are deleted by this push`; anything else halts the task. | T-104-49 | Denial of Service | the D-14 tail-append pushing `computeHourly` past the syscall cap in production | mitigate | Measured directly in Task 3 step 1 against the live instance with a retry-entry check, rather than inferred. A timeout or retry halts phase closure. This is the exact failure mode that killed `evaluateInternal`. |
| T-104-50 | Denial of Service | the deliberately-tripped test budget flooding a real alert channel | mitigate | Exactly one temporary budget is created, tripped, checked for dedup on a second evaluation, and then deleted. D-15's per-period dedup bounds the blast radius to one alert per level. |
| T-104-51 | Information Disclosure | reading `.env` files while checking `ASTRIDR_TELEMETRY_WEBHOOK_URL` and `CLI_GATEWAY_URL` | mitigate | Presence is confirmed via the running container's environment or the gateway's startup log line, never by reading, printing or editing an `.env` file — the env-file guard blocks that path and the value must never appear in output. |
| T-104-52 | Repudiation | a Manual-Only row marked satisfied from a green unit suite | mitigate | Each row requires a cited command output or a described observation with a date; a row that could not be executed is recorded as NOT EXECUTED. `nyquist_compliant` may only be set true when every row genuinely passed. |
