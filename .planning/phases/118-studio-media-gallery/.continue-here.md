## Critical Anti-Patterns

| # | Anti-pattern | severity |
|---|---|---|
| 1 | Trusting a plan's `<automated>` check without mutation-testing it | blocking |
| 2 | Reading a probe's zero/negative without confirming its control behaved | blocking |
| 3 | Letting an executor write `.planning/STATE.md` or `ROADMAP.md`, or calling a `state.*` verb | blocking |
| 4 | Deploying without `--env-file`, or without reading `git status --porcelain` first | blocking |
| 5 | Performing an action a subagent was DENIED permission for | blocking |
| 6 | "Hardening" 118-04's public mutations, or gating anything beyond the ingest path | blocking |

**1 — Mutation-test every check.** SEVEN defective checks have been found in this phase's own plans,
every one of which PASSED while blind to the thing it existed to assert: 118-02 Task 1 regexed the
WHOLE FILE for a verdict string (passed with the verdict deleted); 118-02 Task 3 used a substring
test blind to `openart-mcp` vs `openart-mcp-interactive`; **118-03 Task 3's `npx convex data <table>`
returns "There are no documents in this table." at exit 0 for a NONEXISTENT table — it could never
have failed, and it was the deploy-landed check**; 118-07 hit Windows-backslash escaping producing a
false "missing dir"; 118-05's mutation-proof passed vacuously because no test combined
unauthenticated WITH malformed JSON; 118-06's passed vacuously because the fixture sat exactly ON the
30-day cutoff; 118-04's `.collect()` grep was blind to comments. Three were caught by executors in
their own work. **Mechanism: break what the check should catch, confirm RED, restore, prove the
restore with an empty `git diff` on that file.** Put fixtures well clear of any threshold.

**2 — A control that does not behave means the PROBE is broken.** This bit the orchestrator twice.
`tee file | head -5` SIGPIPEs the writer: a table listing returned 0 for the subject AND 0 for a
known-present control because the file was truncated at 70 of 164 lines — without the control it
would have been reported as a failed deploy. And `grep '^-[^-]'` is structurally blind to deleted
markdown bullets (they render as `--` in a diff), reporting 0 ROADMAP deletions where there were 2.
Also: never hand-escape backslashes into a matcher — use `grep -F` / `-SimpleMatch` with the literal
typed as it appears on disk. And grep BARE NAMES: this codebase declares functions as
`export const X = query({`, so a `function X` pattern is a guaranteed false zero.

**3 — The orchestrator is the single writer for STATE.md and ROADMAP.md.** `state.begin-phase`
CLOBBERED STATE.md at this phase's start: it returned a clean four-field payload while producing 80
deletions against 12 non-blank additions — `completed_phases` 11→9 (a regression), `completed_plans`
71→73 (a rise with zero plans executed, and exactly the naive `*SUMMARY.md` trap value), `percent`
92→75, the entire counter-derivation comment block deleted, and the whole narrative destroyed.
Recovery: `git checkout HEAD -- .planning/STATE.md`, prove an empty `git diff HEAD`, re-apply only
the intended fields by hand with the frontmatter and body copies written from ONE variable. Counters
are re-derived from disk each wave, never incremented. **Note the coherence guard's counter half
SELF-SKIPS here** ("no ROADMAP Progress rows for milestone 'v14.0'"), so its PASS covers
frontmatter/body agreement ONLY — check counters by hand.
