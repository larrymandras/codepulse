**7 — exit 0 is not success.** `node hooks/studioThirdLeg.mjs` exited **0, printed nothing and
wrote nothing**, because `main()` was exported but never invoked — there was no entry-point block.
At the shell that is indistinguishable from success. Caught only because the command prints JSON on
success and none appeared, then confirmed with a file-count probe whose control listed the five
pre-existing vault files. **Mechanism:** assert on the observable outcome (a file exists, a row
returns, bytes changed), never on `$?` alone. A regression test now asserts the guard exists *and
names its own file* — a copy-pasted guard naming another module would never fire.

**8 — do not write a green into a durable artifact early.** `completed_phases` stays 11 and the
ROADMAP box stays unticked precisely because the verifier has not run. This is the same shape as
the seven earlier defective checks: a status recorded against something not yet measured.
