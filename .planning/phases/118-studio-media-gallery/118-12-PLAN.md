## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Higgsfield CLI / external service → host filesystem | Downloaded media bytes and generator-reported metadata are written into the vault. |
| `mediaModels.recipeMd` → an authoritative-looking instruction set | Whatever a card says is what `/studio-generate` will do next time. |
| `npx convex run` → live deployment | An attended CLI invocation against production. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-118-04 | Information Disclosure | a credential value inside `recipeMd`, the skill file, or the evidence artifact | mitigate | D-12: names only, never values. Enforced at three layers — the `upsertModelCard` guard (with an acceptance-case control proving it does not simply refuse everything), a token-shaped-string scan of the skill file, and an acceptance criterion requiring the card to be quoted and confirmed value-free before the plan closes. |
| T-118-02 | Elevation of Privilege | a public card writer letting anything that can route to the host author an authoritative recipe | mitigate | `upsertModelCard` is `internalMutation`, invoked attended via `npx convex run` with the deployment's admin credentials. Asserted by a test. |
| T-118-10 | Tampering | `npx convex run --push` silently deploying the working tree of a shared checkout | mitigate | The plan forbids `--push` and `--prod` on that command by name and explains why. This is the exact flag-rides-on-the-modifier failure that shipped an unauthorised production deploy on 2026-08-11: `convex run` is read-only, `--push` is not. |
| T-118-38 | Spoofing | a recipe card for a model nobody has run reading as verified | mitigate | D-12: an acceptance criterion requires listing every `mediaModels` row and cross-checking each against the evidence file, so a transcribed card cannot survive the plan's close. |
| T-118-39 | Tampering | a hand-constructed CLI invocation producing a confident false negative | mitigate | The Higgsfield subcommand and flags are read off the installed binary's own `--help` and paired with a known-valid control invocation, because a well-formed rejection from a real tool is indistinguishable from an entitlement verdict when the identifier was guessed. |
| T-118-40 | Tampering | retrofitting the eight existing media skills, drifting the contract | mitigate | D-11: an acceptance criterion requires `git status --porcelain` to show zero modifications under all eight named skill directories. |
| T-118-SC | Tampering | npm/pip/cargo installs | accept | No packages installed. The Higgsfield CLI is already present (`higgsfield account status` succeeded 2026-08-13). `118-RESEARCH.md`'s Package Legitimacy Audit records zero new packages and three REMOVED non-existent OpenArt names. |
