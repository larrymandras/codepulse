**PowerShell 5.1 hazards that apply to every file in this plan** — all of these have bitten here
before: write ASCII-only (a UTF-8 em-dash parses as a curly quote and yields "missing terminator");
never redirect native stderr directly under `$ErrorActionPreference='Stop'` (wrap native calls in
`cmd /c "... 2>&1"` and check `$LASTEXITCODE`); use
`IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)` for the elevation check, never the
string form, which returns False in a genuinely elevated shell and can cause an infinite UAC
relaunch loop; and wrap the ASSIGNMENT in `@()` when a command may return one item
(`$x = @(if (...) { ... })`), because a one-element array unrolls to a scalar whose `.Count` is
still 1.

  the watcher wrapper wraps node.
