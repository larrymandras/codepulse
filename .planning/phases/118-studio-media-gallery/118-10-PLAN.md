<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `media` row fields → rendered DOM | `filename`, `prompt`, `model`, `project` are agent- and generator-authored free text arriving from an ingest route. |
| `thumbnailUrl` → `<img src>` | A server-resolved URL string is placed into the DOM. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-118-05 | Tampering (stored XSS) | rendering agent-authored row text | mitigate | All row text renders as React children (auto-escaped). `dangerouslySetInnerHTML` appears nowhere in this plan's files — assert `grep -c "dangerouslySetInnerHTML" src/components/studio/*.tsx src/pages/Studio.tsx` returns 0. Same rule Galdr states inline for prompt bodies. |
| T-118-34 | Tampering | a hostile `thumbnailUrl` (e.g. a `javascript:` or `data:` URL) reaching `<img src>` | mitigate | `thumbnailUrl` is produced server-side by `convex/media.ts`'s single resolver (Convex `_storage` URL or the fallback base URL plus a stored relative path) — it is never taken from the sidecar. The card additionally renders the fallback block on `onError`, so a non-loading URL degrades to a placeholder rather than an empty card. |
| T-118-03 | Denial of Service | the browser fetching an original media file | mitigate | D-02: nothing in the page uses `absPath` as an `src` or `href`, there is no lightbox, and the detail panel (plan `118-11`) shows the same bounded thumbnail. Asserted by inspecting every `absPath` occurrence. |
| T-118-35 | Spoofing | a provenance-absent row reading as provenance-bearing | mitigate | The `No provenance recorded` badge renders on the CARD, not only in the detail panel, so the two states are distinguishable in the same grid view — this is D-07's control pair made visible and is exactly the 117 D-03 rule (an absent signal must never render as a positive one). |
| T-118-16 | Information Disclosure | `absPath` shown in the UI | accept | A host filesystem path displayed to a single operator on a tailnet-bounded instance; offered as copy-to-clipboard only, never as a fetchable link. |
| T-118-SC | Tampering | npm/pip/cargo installs | accept | Zero new packages: the masonry is pure Tailwind (a JS masonry library is forbidden by CONTEXT.md) and all 12 shadcn primitives the UI-SPEC names are already installed. `git diff package.json` showing no dependency change is an acceptance criterion. |
