  <action>
Create `hooks/studioFal.mjs`. No shebang. `node:` builtins only. Structured as exported pure-ish
functions plus a thin CLI entry, with `fetchImpl` and the clock injected through a `deps` parameter
so the whole state machine is testable without network access.

Export and implement:

- **`resolveFalConfig(env)`** — reads `FAL_KEY` using the three-tier order `loom-emit.mjs`
  establishes. **No default and no fallback** — a missing key is a configuration error, exit code 2,
  never an unauthenticated request. The key is read here and never printed anywhere.

- **`submitJob(modelId, input, config, deps)`** — POSTs to fal.ai's queue submit endpoint with the
  documented auth header format (verify it; do not assume `Bearer`), returns the request id and the
  status URL the API hands back. Use the URLs the API returns rather than reconstructing them —
  reconstructing a URL from a template is how a version drift becomes a confident 404.

- **`pollJob(statusUrl, config, deps)`** — polls until a terminal status, with a **bounded** attempt
  count and a bounded total wall-clock budget, with backoff. Every request carries an
  `AbortController` timeout. Terminal states map to `{ ok: true, resultUrl }` or
  `{ ok: false, reason }`. An exhausted budget is `{ ok: false, reason: "POLL_TIMEOUT" }` — never an
  infinite loop and never a silent success.

- **`withRetry(fn, opts)`** — a bounded retry wrapper following `veo.ts`'s structure. Retry only
  transient conditions (network errors, 429, 5xx). **Never retry a 401 or a 4xx validation error** —
  retrying an auth failure turns one clear error into a rate-limit ban and hides the real cause.

- **`downloadResult(resultUrl, destPath, deps)`** — streams the result bytes to disk. Stream it; do
  not buffer a video in memory. Assert the destination resolves inside `media-vault\gen\` before
  writing.

- **`generate({ modelId, prompt, params }, config, deps)`** — the composed flow, returning everything
  `/studio-generate` needs to write the sidecar per `docs/studio-sidecar-contract.md`: the model id,
  the provider (`fal`), the prompt, the params actually sent, and the local file path.

- **`main()`** — a CLI entry so the skill can shell out to it, with `loom-emit.mjs`'s exit-code table
  and no secret ever printed, including in error messages that echo request details.

**Tests** in `hooks/__tests__/studioFal.test.mjs` (inject `fetchImpl`; no network):
- Happy path: submit returns an id and status URL; poll returns `IN_PROGRESS` twice then `COMPLETED`;
  the result URL is extracted. Assert the poll count is exactly 3 — a test asserting only the final
  success would pass against a client that never polls.
- **Poll bound (control pair).** A mock that never reaches a terminal state → `POLL_TIMEOUT` after
  exactly the configured maximum attempts, and the total elapsed budget is respected. Control, same
  block: a mock that terminates on the last permitted attempt → success. This pair proves the bound
  is a bound and not an off-by-one that ends one attempt early.
- **Retry policy (control pair).** A 500 is retried up to the limit; a 401 is retried ZERO times.
  Assert both call counts in one test. Retrying an auth failure is the specific mistake here.
- Auth header present on every outbound request. Control: with `FAL_KEY` unset, `main()` exits 2 and
  `fetchImpl` was never called (assert call count 0).
- Secret hygiene: force an error path that echoes request details and assert the captured log
  contains no `FAL_KEY` value.
- Path safety: `downloadResult` refuses a destination resolving outside `media-vault\gen\` with zero
  filesystem writes.
- **Prove it is not a stub.** Assert `hooks/studioFal.mjs` contains no `not implemented` throw and no
  `TODO` marker in any exported function body — the specific failure mode of its donor. Control:
  confirm the same grep DOES find the marker in `veo.ts`, so a zero here is meaningful rather than a
  broken pattern.
