`POST /studio/ingest` — `Authorization: Bearer <STUDIO_API_KEY>`, `Content-Type: application/json`

Request body:
- `contentHash` (string, required) — SHA-256 hex of the file bytes; D-05's row identity
- `filename` (string, required)
- `absPath` (string, required)
- `mediaType` (string, required) — `"image" | "video" | "audio"`
- `kind` (string, required) — `"gen" | "ref" | "style"`
- `sizeBytes` (number, required)
- `thumbStorageId` (string, optional) — populated on the D-01 `convex-storage` branch
- `thumbRelPath` (string, optional) — populated on the D-01 `local-static-origin` branch
- `width`, `height`, `durationSec` (number, optional)
- `sidecar` (object, optional) — ABSENT means D-07 provenance-absent. When present may carry
  `prompt`, `model`, `provider`, `style`, `project`, `params`, `tags`

Responses:
- `200 {"ok":true,"mediaId":"...","created":true}` — new row
- `200 {"ok":true,"mediaId":"...","created":false}` — D-06 duplicate hash, zero writes
- `400 {"error":"INVALID_JSON"}` / `400 {"error":"MISSING_FIELD","field":"<name>"}` /
  `400 {"error":"INVALID_ENUM","field":"<name>"}` / `400 {"error":"THUMB_TOO_LARGE"}`
- `401 {"error":"Unauthorized"}` — from the shared `unauthorizedResponse()`

Second route, same auth, for the D-01 `convex-storage` branch only:
`POST /studio/upload-url` → `200 {"ok":true,"uploadUrl":"..."}` — wraps
`internal.media.generateThumbUploadUrl`. On the `local-static-origin` branch this route is NOT
registered; say which in the SUMMARY.
