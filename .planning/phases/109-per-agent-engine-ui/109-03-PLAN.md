<objective>
Retire the D-16 stub seam in one atomic change: delete the stub adapter, its fixtures, the
build-time flag, all five STUB render sites, the client-side validator, and the two WS commands
Ástríðr never implemented — and replace them with the real, live path (`swap.set` with
`profile_id`, one `swap.catalogue` for both scopes, `default_profile_id` from Ástríðr).

Purpose: the picker's DEFAULT scope is "profile", so today the default per-profile path dispatches
`gateway.model.set`, which Ástríðr's dispatcher registry does not register at all — an unknown
`type` fails Pydantic union validation and returns an error ack. Nothing per-profile can work
until this lands. It is also the T-103-03 mitigation: a build-time flag deciding whether the
operator sees real or fabricated data cannot survive inside the milestone whose purpose is
removing fabricated readings.
Output: a compiling tree with no stub concept in it, dispatching real commands.
</objective>
