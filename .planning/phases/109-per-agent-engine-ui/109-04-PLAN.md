<objective>
Fix the read path so every brain surface answers "what engine is this profile on?" the same way
Ástríðr does, and says "Not reported" instead of inventing an answer when it does not know.

Purpose: three of this phase's four inherited defects live here. `resolveActiveBrain` checks the
GLOBAL override first and returns early (`useResolvedBrain.ts:252-254`), while Ástríðr resolves a
per-profile override ABOVE the global one — so a pinned profile currently renders the global model
while Ástríðr will actually use the pin. The scoped `lastTurn` rung feeds a FLEET-wide model into a
PER-PROFILE read, justified by a docstring premise Phase 108's D-01/D-11 falsified. And three
different strings render for the identical "no telemetry" condition, one of which ("Auto") is a
fabricated claim about a resolution that never happened.
Output: one resolver with the correct rung order, one new live-state hook feeding it, and one
canonical absent string across every surface.
</objective>
