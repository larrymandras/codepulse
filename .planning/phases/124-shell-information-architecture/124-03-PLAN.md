## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Convex query ← alerts table | An unbounded read over a table whose row count is driven by external ingest (`/ingest`, alert evaluation crons). Row volume is the untrusted quantity, not row content. |
| public Convex function ← any host that can route to the backend | `countBySeverity` is a public query, callable without credential by anything on the network path (`CLAUDE.md`, measured 2026-08-11). |
