### `SectionErrorBoundary` — read it before assuming a fallback exists

`src/components/SectionErrorBoundary.tsx` (65 lines, read live 2026-08-21) takes
`{ children, name? }` **and has no `fallback` prop**. Its error render is a fixed card: `p-4`, an
`w-8 h-8` icon circle, a message paragraph and a Retry button. That is correct for a dashboard
widget and completely wrong for a 232px sidebar row or a 48px header slot — dropping it inline
would break the shell's layout the moment a shell query fails, which is the opposite of what D-13
is protecting.

So this plan adds an OPTIONAL `fallback?: ReactNode` prop, rendered in place of the card when
supplied. This is additive: 20+ existing call sites pass only `{ children, name }` and are
unaffected. There is no `SectionErrorBoundary.test.tsx` in this repo (checked).

### Badge primitives

- Neutral Inbox count: compose the base `Badge` (`src/components/ui/badge.tsx`) with
  `bg-(--surface-3) text-(--foreground) border border-(--hairline)` per the UI-SPEC's Sidebar
  Contract. Read `badge.tsx` first to confirm the base variant's own classes do not fight the
  override — `StatusBadge.tsx:172` already handles this by passing `variant="secondary"` plus a
  `cn()` override, which is the in-repo precedent.
- Severity-bearing Alerts count: compose `StatusBadge`
  (`src/components/StatusBadge.tsx:163-176`), whose props are `{ status, label, tier? }`. `status`
  accepts direct semantics (`"ok" | "error" | "warn" | "idle" | string`) and any value not in
  `legacyMap` falls through to `defaultTierForSemantic` — so pass semantic + explicit `tier` +
  explicit `label` together, the "direct-semantic-literal caller" convention its own comments at
  `:88-98` describe.

shared wrapper around several.

      never disagree: `critical > 0 || error > 0` → `StatusBadge status="error" tier="strong"`;
      else `warning > 0` → `status="warn" tier="quiet"`; else (info only) → the same neutral pill
      as Inbox. In every case the LABEL is the total unacknowledged count.
    - Digits use the Data typography role: 12px, JetBrains Mono, weight 600, `tabular-nums`.

    **Truncation honesty:** plan 124-03 made `countBySeverity` return `truncated: boolean`. When it

    trailing `+` and set the accessible label to "at least {n} unacknowledged alerts". Rendering a

    naming the domain — `"{n} unread in Inbox"` and `"{n} unacknowledged alerts"`. Do not make the
    badges an `aria-live` region.

    Do not render badges when the sidebar rail is collapsed to 48px, where there is no room for a
