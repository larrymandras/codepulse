## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL path → rendered breadcrumb text | `useLocation().pathname` is user-controllable (anyone can type a URL) and its trailing segment is rendered as the breadcrumb's detail segment. This is the one genuinely untrusted input this phase introduces into the shell. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-124-09-01 | Tampering | URL segment rendered into the breadcrumb | mitigate | The detail segment is rendered as React text content, which escapes by construction — do NOT introduce `dangerouslySetInnerHTML` anywhere in the breadcrumb. Only routes matching `DETAIL_ROUTE_PARENTS`' static prefixes get a third segment at all; every other unmatched path yields an EMPTY trail and renders nothing, so an arbitrary path cannot inject arbitrary chrome text. |
| T-124-09-02 | Repudiation | A breadcrumb naming a record the shell never read | mitigate | The detail segment is the raw URL param, explicitly not a resolved display name, and the module docstring records why. Inventing "Hildr" from an id the shell cannot look up would be the fabrication class POLISH-04 exists to prevent. |
| T-124-09-03 | Repudiation | Deleting real telemetry to satisfy a layout | mitigate | D-08 relocates SYS/LAT rather than deleting them, their `showSys`/`showLat` gating is preserved verbatim, and Task 3 keeps Phase 96's real-or-hidden tests alive with a mutation proof that they still discriminate after the move. |
| T-124-09-04 | Denial of service | Zone-1 content re-inflating the header's min-content width | accept-then-measure | Deferred to plan 124-10 by design: D-06 forbids asserting the height from the spec and requires a re-measurement. This plan is explicitly forbidden from touching the height classes, so it cannot pre-empt that decision. |
| T-124-09-05 | Information disclosure | Route identifiers visible in shared chrome | accept | The path is already in the address bar; the breadcrumb restates it. No record content is read or displayed. |
| T-124-09-SC | Tampering | npm/pip/cargo installs | accept | Zero installs; the breadcrumb is a plain `<nav>`/`<ol>` with no primitive needed; `components.json` → `"registries": {}`. |
