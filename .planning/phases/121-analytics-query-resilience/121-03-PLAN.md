<objective>
Create the eight self-fetching components that will receive the queries currently hoisted into
`Analytics()`'s function body. This plan creates files only; plan 121-04 rewires the page.

Purpose: a `useQuery` throw happens during the render of the component that CALLS it. A
`SectionErrorBoundary` placed around the Summary Row's JSX inside `Analytics()` is never an ancestor
of a call made in `Analytics()`'s own body, so it can never catch that throw. Relocating the call into
a child is not one option among several — it is the only construction under which a boundary can
work. This is why D-02 says "push queries down into boundary-wrapped children" and why D-03 rejects a
route-level boundary as a substitute.
Output: eight components, each owning its own fetch and rendering today's markup unchanged.
</objective>
