**The D-01 structural constraint, stated as a code rule:** the walk function's dependency set must
contain **no read capability**. Declare it as:

`export function walkRoot(root, config, deps)` where `deps` destructures **exactly**
`{ readdirSync, statSync, mountedSet }` and nothing else. There is no `readFileSync`, no `readFile`, no
`createReadStream`, no `openSync` and no `fs` module reference anywhere in this function or in anything
it calls. It is not "we chose not to read"; there is nothing in scope that could.

  types, avoiding a `statSync` per entry just to distinguish files from directories. Fall back to

- For each directory, produce ONE row (D-13): `{ rootId, dirPath, department, access, fileCount, totalSize, latestMtime, withheldCount }`.

  - `department` = `resolveRootDepartment(root.id, config)`.
  - `access` = `resolveAccess(absoluteDirPath, deps.mountedSet)`.

    `classifyFile({ rootId: root.id, relPath, basename }, config)`:
