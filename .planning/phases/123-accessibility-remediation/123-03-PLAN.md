## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dev server → Playwright page | The scan navigates a locally-served development build. Page content is developer-authored, not attacker-supplied. |
| shell env → test matrix scope | `A11Y_SCAN_ALL`, `A11Y_MEASURE_ONLY`, `A11Y_CAPTURE_DIR` are developer-set switches that widen or narrow the run. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-123-07 | Spoofing | "the suite scanned 47 routes" | mitigate | The C5 test asserts `ALL_ROUTES.length === 47`, asserts the generated cell count equals `themes x routes`, and asserts the value is not 62 — so an under-enumerated scan fails instead of reporting green for routes it never visited. |
| T-123-08 | Spoofing | "the page rendered" | mitigate | Per-route content markers replace the app-shell nav; a missing marker fails the cell. The `Main navigation` locator survives only inside the Clerk-gate branch, where distinguishing gated from ungated is exactly its job. |
| T-123-09 | Repudiation | `A11Y_MEASURE_ONLY` runs | mitigate | A measurement run now ends non-zero carrying a fixed, greppable message, so a measurement can never be filed as a verification in a log. |
| T-123-10 | Information disclosure | `A11Y_CAPTURE_DIR` output | accept | Captured axe JSON contains rendered page markup from a local dev server with no real credentials. Capture directories are written under `.planning/` or a temp path and reviewed before commit, consistent with Phase 122's handling of the same artifacts. |
| T-123-SC | Tampering | npm/pip/cargo installs | mitigate | Not applicable — zero packages added; no install task exists in this plan. `123-RESEARCH.md` § Package Legitimacy Audit records the same. |
