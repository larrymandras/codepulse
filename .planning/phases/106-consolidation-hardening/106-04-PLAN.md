<interfaces>
The two lazy-boundary patterns already established in this codebase. Use them; do not invent a third shape.

Route-level lazy — `src/App.tsx`, used by 30+ pages today. Declaration form:
`const Chat = lazy(() => import("./pages/Chat"));`
Route form: the `Route` element wraps the page in a `Suspense` whose `fallback` is
`<div className="text-muted-foreground text-base p-8 text-center">Loading Chat...</div>`

Sub-component lazy with a named export — `src/components/graph/CodeVaultGraph.tsx`. Module-level declaration, which avoids React's "lazy inside component" warning:
`const LazyForceGraph3D = lazy(() => import("./ForceGraph3D").then((m) => ({ default: m.ForceGraph3D })));`

Isolation-rule docstring convention — `src/components/graph/ForceGraph3D.tsx` lines 10-17. Its wording: this is the ONLY file permitted to import the heavy package; the dynamic-import boundary keeps it out of the main bundle; importing it from any file statically reachable from main would break chunk isolation. Apply the same discipline to whatever file becomes the sole import site of a deferred heavy dependency.
