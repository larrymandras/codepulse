<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| keyless dev server (`:5181`) → network | An auth-disabled server runs during the checkpoint |
| Convex-stored briefing prose → operator's screen and the verdict file | Real briefing content is displayed and may be quoted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-125-10-01 | Elevation of privilege | the auth-disabled `dev:noauth` server | mitigate | `npm run dev:noauth` pins `--host 127.0.0.1`, deliberately overriding `vite.config.ts`'s `server.host: true`, which would otherwise expose an AUTH-DISABLED server on the tailnet and LAN. Never drop that flag, and never substitute a plain `npm run dev` with the Clerk key blanked. |
| T-125-10-02 | Repudiation | a verdict nobody actually gave | mitigate | The verdict is transcribed verbatim from the operator's reply and must not be inferred from silence or from an absence of complaints. An issues-instead-of-verdict outcome explicitly does not complete this plan. |
| T-125-10-03 | Spoofing | judging the wrong typeface | mitigate | `document.fonts.check` for the real family with a bogus-family control, plus the computed `fontFamily`/`fontStyle` pair, all recorded in the artifact. A verdict rendered on Georgia's synthetic italic would be a verdict about a face that would never ship — the exact R-6 defect. |
| T-125-10-04 | Repudiation | judging an empty page | mitigate | The spec FAILS rather than skips when no populated `briefing-voice` element appears. A capture taken before the query resolves records a clean page that is not clean — this repo has already lost four accessibility findings to that exact defect class. |
| T-125-10-05 | Information disclosure | briefing prose quoted into a committed planning file | accept | Only the operator's own reasoning is quoted, not briefing content. If reasoning necessarily quotes a briefing, the executor must redact identifying content before writing the file and say that it did so. |
| T-125-10-SC | Tampering | npm/pip/cargo installs | mitigate | This plan installs nothing. |
</threat_model>
