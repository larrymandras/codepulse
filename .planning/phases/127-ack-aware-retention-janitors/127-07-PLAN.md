<objective>
Perform Verification B's mutation-testing control: delete each carve-out guard, confirm the
outcome FLIPS, restore.

Purpose: a passing carve-out test proves nothing on its own. If removing the guard leaves the
test green, the test is not exercising the exclusion — it is passing for some unrelated reason,
and a future edit that drops the guard will ship silently. `127-CONTEXT.md` calls this "the
focus_digest regression guard" and says plainly: it is not optional.

This is the only check in the phase that could have come out the other way for the carve-outs.
The absent-field guarantee is structural and survives any predicate edit; the carve-outs have
no database-level backstop at all. Nothing fails when they are removed except a test written to
catch it — and this task is what establishes that such a test exists.

Output: no code changes. A recorded verdict, three flips confirmed.
</objective>
